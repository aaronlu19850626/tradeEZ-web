# 系统架构

```text
交易平台/EA/连接器
  → FastAPI 接入、鉴权、幂等和审计
  → PostgreSQL 原始事实与可重建业务投影
  → Next.js 工作台
  → 统计、计划、复盘和 AI 辅助
```

## 架构约束

- 连接器只上传平台原始事实；业务统计由服务端统一计算。
- 原始成交、快照和同步事件可追溯且幂等；派生交易和统计可重建。
- API 按用户、账户和权限隔离；敏感凭证加密保存并记录访问。
- 前端页面不复制统计口径、权限和金额计算；通过 API 契约和共享类型消费。
- 异步任务、缓存和外部数据缺失时必须可降级，不得伪造交易事实。

## 代码事实

- `backend/app`：FastAPI 应用和业务域。
- `backend/migrations`：PostgreSQL schema 和版本迁移。
- `frontend/src`：Next.js 路由、组件、数据访问和测试。
- `connectors`：平台适配器和协议客户端。

模块设计不能与本文件重复架构原则；具体契约以代码、schema、测试和当前模块规格为准。
