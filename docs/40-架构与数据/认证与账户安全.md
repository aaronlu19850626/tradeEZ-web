# 认证与账户安全

- 登录、注册和验证码流程必须由服务端验证、限流、过期和审计；测试验证码只允许在隔离开发环境启用。
- 会话使用当前后端定义的 JWT/会话机制；前端不得自行判断用户权限或绕过服务端保护。
- 交易账户、同步 Key、外部平台 Token 和 AI 数据权限按当前用户隔离。
- 同步 Key 只显示一次或以明确的可恢复密文保存；日志、Issue、PR 和错误响应不得包含明文秘密。
- 高风险操作（重置、删除、撤销、数据导出、AI 权限改变）必须有权限、确认、幂等和审计记录。
- 生产配置、SMTP/SMS 密钥、数据库 URL 和 GitHub Secrets 只能放在受控环境变量或 Secret Store。

新认证或账户模块必须在 Issue 中写明威胁边界、错误响应、审计事件、测试账号和回滚方式。
