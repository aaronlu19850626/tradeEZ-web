# 连接器架构

连接器负责平台适配，不在账户、交易和统计模块复制平台分支。每个平台声明能力、鉴权方式、原始字段、同步方向、幂等键、限流和错误语义，再转换为统一交易事实。

当前可用能力以代码、[EA 同步协议](EA同步协议.md)和测试为准。前端展示平台选项不代表后端已经支持同步；连接器状态必须区分可同步、文件导入、即将上线和暂不支持。

## 新平台流程

1. 研究官方协议和授权边界。
2. 创建连接器研究/开发 Issue。
3. 定义原始事实、字段映射、幂等、重试、撤销和审计。
4. 在隔离环境实现适配器和契约测试。
5. 验证统一交易投影、账户隔离和重复同步。
6. 通过 PR 后再加入平台注册表和 UI 入口。

凭证必须加密保存；旧 MT5 SOP 接口继续兼容，不作为其他平台的通用接口。
