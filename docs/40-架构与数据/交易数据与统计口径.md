# 交易数据与统计口径

## 核心模型

```text
连接器原始成交/快照
  → 归一化事实
  → 交易生命周期和分摊投影
  → 查询、统计、复盘和 AI 引用
```

原始事实不可覆盖；投影可以在规则变化后重建；人工复盘资料通过账户、交易和版本关系独立保存。

## 统一口径

- 时间以 SOP 和当前 schema 规定的 UTC/账户展示规则处理，页面不能按浏览器本地时区重新解释。
- 净盈亏、费用、胜率、利润因子、盈亏比和回撤由服务端共享实现。
- 币种是账户级权威属性；未确认汇率换算前不跨币种合计。
- 国内市场和外汇市场的涨跌色只影响收益/行情语义，不改变错误、危险、成功等产品语义色。
- 缺失数据显示 N/A 或明确“数据不足”，不能用零伪造结果。

统计、缓存和性能优化必须保留可解释来源、筛选条件和失效规则。
