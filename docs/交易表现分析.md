# 交易分析与交易日历（首版）

已接入 `/dashboard/analytics` 与 `/dashboard/calendar`，替换演示入口并解除菜单禁用。

## 接口及口径

`GET /api/v1/my/performance?account_id=…&start_date=YYYY-MM-DD&end_date=YYYY-MM-DD`

- 登录用户只能访问自己绑定的单一账户，不跨币种合计。可按 symbol（包含匹配）、direction（buy/sell）筛选。
- 日期区间双端包含，最多 3661 天。按新 SOP 和主 EA 上报的 UTC 时间归属日期，不额外偏移浏览器或服务器时区。
- 仅纳入 complete 生命周期，按最后平仓时间归属日期；部分平仓生命周期在全部平仓后一次计入，包括其所有费用。
- 未平仓与待核对数量是当前品种/方向下的全历史数量，不是指定期间内的排除数量，页面明确注明。
- 胜率包含持平交易作为分母。利润因子为正净收益合计除以负净收益绝对合计；无亏损返回 null。
- 盈亏比为平均盈利除以平均亏损绝对值；缺少任一类返回 null。
- 最大回撤按期间内逐笔平仓顺序（同秒按 Trade ID）从零累计计算。此值不是账户权益回撤，不含浮盈亏和入出金；图表按日展示累计值。
- 金额在汇总时使用 Decimal，源数据来自现有生命周期投影。成交修正触发的重建会反映到下一次统计查询。

## 页面

首次打开使用首个账户最近成交月份，支持账户、日期、品种、方向筛选。日历点击日期显示对应交易，点击编号复用交易来源抽屉。加载、失败重试、空数据和未绑定账户均有提示。

## 验证与限制

后端测试覆盖初始亏损回撤、逐笔回撤、空样本、无亏损比率、跨日边界、开平费用、所有权、筛选和源成交修正。

此版本暂不提供策略/标签分组、R 倍数、资金收益率、账户权益曲线及导出。统计目前在单账户投影上读取并聚合，海量历史优化和日明细分页尚需后续实现。

pytest 的发现目录限制为 tests，避免 scripts/v2_smoke_test.py 在收集阶段初始化另一份测试环境。EA 冒烟脚本继续单独运行。

## 按复盘标签与状态筛选

分析与日历支持 tag（精确标签，首尾空格忽略）及 review_status（unwritten/draft/reviewed）。筛选作用于当前账户的交易生命周期，仅按同一账户、持仓号、开仓成交锚点匹配人工复盘，不通过持仓号单独匹配，不把待恢复的孤立笔记计入业绩。日期、品种、方向、标签和状态共同作用于汇总、每日曲线、品种统计及日历明细；未完成／待核对排除数沿用全历史口径，但应用当前品种、方向、标签与复盘状态。

分析新增 setup_id 与 execution_status（unrated/compliant/violations/insufficient）。模型和执行状态与既有条件共同过滤；按模型统计包含交易数、净收益、胜率、正式评分数量及平均执行分，未关联模型单独列出。执行分仅在评分规则证据覆盖率达到 100% 时计入平均值。

标签和状态按当前已保存值筛选，后续重命名或复盘修改会改变历史筛选结果。“已复盘”不表示成交修正后已重新核对；此筛选不改变交易是否完整的判断。金额仍只限单账户原币，不涉及不同币种相加。

复盘汇总页选择账户并应用筛选后，可通过链接带入账户、标签与复盘状态。分析日期默认该账户最近成交所在月份；关键词和关联状态不带入，并在入口明确说明。分析页支持清空复盘筛选、刷新统计，日历详情保存复盘后刷新统计。

72 项后端回归测试通过，包含组合筛选、标签精确匹配、汇总／每日／品种一致、孤立笔记不计入及账户权限隔离。
