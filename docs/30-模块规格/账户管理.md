# 账户管理

## 状态和边界

已有账户列表、创建、改名、同步 Key、导入、重置、删除、统计账户和 EA 状态能力，但原设计、后台契约和旧模块下线清单未按当前流程重新确认。本文件只登记已有事实，不授权新开发。

## 现有代码入口

- 前端：`frontend/src/app/(main)/dashboard/account-center/`
- 后端：`backend/app/account_center/`
- 共享同步鉴权：`backend/app/sync/` 和公共加密逻辑

## 长期数据规则

- 账户属于当前用户；同步 Key 只能以不可逆/可恢复的服务端密文方式保存，不能回传明文。
- EA 心跳、快照和最后同步时间是可追溯状态；旧账户模块未验收前不能删除。
- 账户删除、交易重置和 Key 重置必须有权限、审计、确认和回滚边界。
