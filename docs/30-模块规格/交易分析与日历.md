# 交易分析与日历

现有入口为 `/dashboard/analytics` 和 `/dashboard/calendar`，支持账户、日期、品种、方向、标签、复盘状态、策略和执行状态筛选，并使用交易生命周期投影计算净收益、胜率、利润因子、盈亏比和逐笔回撤。

该模块必须与交易记录和总览共享统计口径；当前单账户、时区、未平仓、费用、同秒排序和源成交修正等实现均属于待复核事实。重新研究后再决定一期范围、性能要求、分页和导出边界。
