# AI 中心

AI 中心定位为交易数据和复盘助手，不是交易执行者。它只能读取用户授权的数据，提供摘要、整理、改写、结构化和问答；不能下单、改止损、改账户、删除数据或覆盖用户原文。

历史需求稿提出全局对话、日复盘摘要、单笔交易整理、模型路由、能力权限和计量账单，但这些范围、模型、成本、隐私、审计和供应商尚未按一期重新确认。当前文档不授权开发。

新 Issue 必须先确定数据授权、提示词/记忆、引用来源、流式响应、失败降级、人工确认、内容安全、成本计量和删除审计，再建立 API 和模型适配契约。
