# 交易复盘与每日计划

## 现有能力

历史实现包含单笔复盘草稿/已复盘、标签、截图、保存冲突、待恢复资料、日计划、交易意图和日总结。代码和迁移事实必须以当前 schema、测试和 GitHub Issue 重新核对。

## 复核边界

重新研究单笔交易详情、笔记、标签、附件、策略评价、执行评分、盘前计划、交易意图、盘后总结、版本、冲突和恢复流程。Notebook、笔记历史和笔记模板不从本文件推导需求，必须单独创建研究 Issue。

## 验收出口

确定复盘与每日计划的数据关系、权限、版本策略、API 契约、迁移、移动端和 AI 读取边界后，分别建立可独立验收的子任务。
