## 维护规则

- 所有新文档使用中文文件名和中文标题，并按编号目录归档。
- 文档首行说明版本和状态。
- 冲突以最新评审结论、前端强制规则和 UI 规范为准。
- 文档移动或改名后同步更新引用和代码路径。
- 历史稿进入 `90-历史归档`，不删除历史决策。
- 旧 Notebook 方案归档于 `docs/90-历史归档/Notebook旧方案-20260924/`，不得作为新实现的需求依据。
