# 全局组件迁移范围

版本：1.0；状态：批次 A、B、C 已完成，批次 D 待排期。

## 1. 评审范围

- 交易总览：`frontend/src/app/(main)/dashboard/overview`
- 交易账户：`frontend/src/app/(main)/dashboard/account-center`
- 交易记录：`frontend/src/app/(main)/dashboard/trade-center`
- 三模块共享：`frontend/src/components/filters`、`domain`、`shared`、`dialogs`、`data-table`

不纳入本轮：AI 中心、行情回放、图表实验室、主题评审页和旧演示模块。

## 2. 总体结论

当前三模块的大部分基础控件已经统一：

- 业务表格使用共享 `DataTable` 或标准 Table 语义。
- Dialog 基本遵循 `DialogContent > DialogHeader + DialogBody + DialogFooter`。
- 状态和方向使用标准 `Badge`、`TradeSideBadge`、`SymbolBadge`。
- 简单说明使用共享 `InfoTip`，图标操作使用全局 `Tooltip`。
- 右栏菜单使用 `DropdownMenu`，弹层使用 `Popover`。
- 日期范围、账户范围、复杂筛选器已经抽到 `components/filters`。

剩余问题主要集中在少数交互语义、单选控件和图表 Token 上，不需要重做整个组件体系。

## 3. P0：必须迁移

### MIG-001 日期范围清除操作嵌套在 Button 内

状态：已完成。

文件：

- `frontend/src/components/filters/trade-filter-controls.tsx`

现状：

- 日期范围触发器是一个全局 `Button`。
- 清除图标使用内部 `span` + `onClick`，并用 `biome-ignore` 绕过无障碍规则。
- 存在“交互控件嵌套交互控件”问题，键盘焦点和无障碍语义不完整。

目标：

- 使用 `ButtonGroup` 或 `InputGroup` 将日期触发器和清除按钮拆成两个标准 `Button`。
- 清除按钮改为 `Button`、`size="icon-sm"`、明确的 `aria-label`。
- 保持视觉上仍是一组连续控件，且清除后发送无日期条件。

验收：

- 鼠标点击触发器和清除按钮互不干扰。
- Tab 顺序可分别聚焦触发器和清除按钮。
- Enter/Space 可操作清除按钮。
- 390 / 768 / 1024 / 1440 下不溢出。

### MIG-002 复杂条件分组使用原生 button

状态：已完成。

文件：

- `frontend/src/components/filters/filter-select-controls.tsx`

现状：

- 左侧条件名称导航使用原生 `<button>` + `aria-pressed`。
- 键盘箭头导航、单一选中值和标准键位行为不完整。

目标：

- 改为单值 `ToggleGroup`，或符合筛选器规范的标准 Tabs 语义。
- 保留当前左侧名称、右侧条件选项的结构。
- 选中态继续使用 `primary-soft + primary`。

验收：

- 上下方向键可切换条件分组。
- 只允许一个条件分组处于选中状态。
- 选中分组后右侧内容同步切换。

## 4. P1：建议迁移

### MIG-003 平台和币种平铺单选

状态：已完成。

文件：

- `frontend/src/components/domain/platform-select.tsx`
- `frontend/src/components/domain/currency-select.tsx`

现状：

- 使用 `Button + aria-pressed` 模拟单选。
- 视觉符合用户要求的平铺选择，但语义不是标准单选。

目标方案：

- 使用 `RadioGroup + RadioGroupItem + Label`。
- Radio 视觉保持隐藏或紧凑，卡片仍使用当前平铺表现。
- Label 通过 `focus-within` 显示标准焦点环，键盘方向键切换。
- 保留“平台默认带币种、CTP 锁定 CNY、货币前显示国家图标”的业务逻辑。

需要确认：

- 若要求视觉完全不变，只调整语义；不改变用户已确认的平铺外观。

## 5. P2：保持现状，只记录边界

以下属于已确认的标准扩展点或业务可视化，不迁移：

- 交易记录右侧月历使用官方 `CalendarDayButton` 扩展盈亏数字和线条。
- 总览散点图使用 Canvas 坐标和自定义悬浮提示，因为标准 Tooltip 无法直接绑定 Canvas 数据点。
- 交易指标条、比例条和市场强度条使用语义 Token 绘制，不使用 Badge 替代数据图形。
- 账户平台下方的压缩市场徽标沿用标准 Badge，仅保留已确认的小尺寸变体。
- 账户范围 Chip 使用 `Button + aria-pressed`，属于多选快捷范围控件，保持当前交互，但后续需统一键盘行为。
