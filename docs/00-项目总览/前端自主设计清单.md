## 规则

1. 每个功能点先完成研究，再决定是否需要自主设计。
2. 自主设计优先使用 TradeEZ Token、标准控件和已确认业务模式。
3. 未登记的自主设计不视为完成。
4. 每条记录必须包含参考证据、偏离原因、实现状态和验证结果。
