# 交易账户、交易记录、交易总览功能测试计划

版本：1.0；状态：已执行，55 项浏览器用例全部通过。

## 1. 目标

对当前已经实现的三个核心模块进行逐功能分析，建立可执行的细粒度测试计划，覆盖 UI、API、数据库和跨模块数据一致性。未实现能力不纳入本轮验收。

## 2. 不在本轮范围

- 账户交易报告计算：当前只有入口占位。
- 复盘、笔记编辑、标签、规则评分。
- 单笔订单详情与成交拆分。
- 导出 CSV、合并交易、拆分交易、转移交易。
- 自定义 Dashboard 布局和模板管理。
- 每日检查清单真实数据和评分联动。
- CTP、MT4、cTrader、ATAS 真实连接器同步。

## 3. 测试层级

- `UI`：Playwright 真实浏览器交互与页面断言。
- `API`：FastAPI 接口契约、状态码和响应数据。
- `DB`：PostgreSQL 原始成交、账户投影和派生交易核对。
- `E2E`：从 UI 操作到数据库结果的完整链路。
- `RESP`：桌面、平板、移动端响应式检查。

1. 后端：全量 pytest + 新增重复同步生命周期用例。
