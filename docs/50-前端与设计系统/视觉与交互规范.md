# 视觉与交互规范

## 页面结构

页面使用统一工作台外壳：页面根容器、标题与说明、右侧操作区、筛选/工具栏、主体内容和明确的状态反馈。标题栏、卡片、表格、弹窗、分页和筛选器优先复用现有业务模式。

## Token 和语义

- 颜色、字体、间距、圆角、边框、阴影和主题通过 TradeEZ Token。
- `success`、`warning`、`danger`、`info` 表示系统语义；交易盈亏和市场涨跌使用市场属性映射，不改变危险操作颜色。
- Light/Dark 必须保持对比度和语义一致，不能在页面写死未经批准的颜色。

## 交互状态

每个组件定义默认、hover、active、focus、disabled、loading、empty、error、success、主题、语言和移动端行为。筛选、分页、搜索、Tab、日期范围和弹层关闭行为必须可预测且可键盘操作。

## 复刻边界

可以复刻参考产品的信息层级、核心操作和状态；品牌 Logo、品牌色、文案和产品规则必须属于 TradeEZ。视觉验收必须附适用视口、主题和关键状态截图。
