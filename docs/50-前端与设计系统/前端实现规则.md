# 前端实现规则

- 页面专用代码留在所属路由 `_components/`；跨两个模块复用后才提升为共享业务组件。
- 基础 Button、Badge、Input、Select、Dialog、Table、Tooltip 等只使用 `src/components/ui`；不为单页复制一套基础控件。
- 不修改 `src/components/ui` 和 `src/components/calendar` 解决单个模块需求。
- Server Component 默认优先；浏览器事件、状态和第三方编辑器放入专用 Client Component。
- 使用严格 TypeScript、`@/` 别名、npm、`package-lock.json` 和 Biome 规则，避免无必要依赖。
- 新页面必须有语义 HTML、键盘支持、可见焦点、标签、合适 ARIA、加载/空/错误/禁用/成功/溢出处理。
- 新页面必须在 390、768、1024、1440px 和 Light/Dark 下检查；中英文文案通过统一资源管理。
- 参考页面按[TradeZella 研究规范](../20-产品与研究/TradeZella研究规范.md)研究后实现，使用 TradeEZ Token，不复制品牌样式。

组件或非标准语义控件进入共享目录前，必须在 Issue 说明复用理由、状态、可访问性、响应式、主题、语言和测试计划。
