# 组件库治理

## 分层

1. `src/components/ui`：shadcn/Radix 基础组件，保持来源和 API 稳定。
2. 应用共享组件：导航、主题、布局和通用交互。
3. TradeEZ 业务模式：表格、页面标题/工具栏、状态标签、空/错/加载、危险确认、筛选器、分页、统计卡、编辑器工具栏。
4. 模块专用组件：只在所属路由和模块规格中使用。

## 提升条件

组件跨两个模块复用，或出现统一状态、尺寸、可访问性和主题要求时，才提升为共享业务组件。提升必须经过 Issue、使用方清单、API/状态设计和设计系统页面验收。

## 交付要求

每个共享组件必须记录用途、输入输出、默认/hover/active/focus/disabled/loading/empty/error/success、主题、语言、移动端、可访问性和截图。业务组件不复制基础 Button、Dialog、Table 或 Tooltip。
