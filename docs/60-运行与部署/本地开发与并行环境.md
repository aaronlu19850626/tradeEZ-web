# 本地开发与并行环境

## 单任务

从最新 `origin/main` 创建独立 worktree；前端默认 3000、后端 8000。环境变量分别放在本地忽略文件中，不提交秘密。

## 多任务

每个 worktree 必须独立使用：

```text
前端端口：TRADEEZ_FRONTEND_PORT
后端端口：TRADEEZ_BACKEND_PORT
开发库：tradeez_dev_<task>
测试库：tradeez_test_<task>
E2E 库：tradeez_e2e_<task>
临时目录、上传目录、Playwright 状态和日志：<task> 专属目录
```

多个 worktree 只隔离代码，不自动隔离 PostgreSQL、Redis、Docker、认证文件或远程服务。启动前必须检查实际 `DATABASE_URL`、端口和状态目录。

## 启动和检查

```bash
cd backend && source .venv/bin/activate
python -m uvicorn app.main:app --host 127.0.0.1 --port "$TRADEEZ_BACKEND_PORT"
cd frontend && npm run dev -- --port "$TRADEEZ_FRONTEND_PORT"
```

健康检查、数据库迁移和浏览器门禁必须使用当前任务环境。禁止用开发库、共享测试库或生产库运行自动化清理。
