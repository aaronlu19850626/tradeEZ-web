# 部署与生产测试环境

## 环境边界

生产测试环境用于验收和联调，独立于真实生产数据。连接串、证书、短信/邮件和第三方密钥只能放在受控 Secret/Environment 中；日志、Issue 和 PR 不显示秘密或真实用户数据。

## main 发布流程

```text
PR 合并 main
→ CI 构建和门禁
→ GitHub Environment 审批（高风险变更必需）
→ 备份生产测试库
→ 执行未应用迁移和幂等系统 Seed
→ 核对 schema 版本
→ 部署对应代码
→ /health、API、登录和关键浏览器回归
→ 在 PR/部署记录回填结果
```

数据库同步规则详见[数据库变更与环境同步](../10-开发与协作/数据库变更与环境同步.md)。不从本地导出数据库覆盖生产测试库，不直接修改远程 schema。

## 回滚

应用回滚使用新的 revert PR；数据库回滚使用经过验证的恢复或补偿迁移。发布记录必须包括版本、迁移、备份、负责人、健康检查、失败点和恢复点。
