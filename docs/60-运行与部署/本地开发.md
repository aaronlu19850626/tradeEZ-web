# 本地开发与联调

## 后端

```powershell
cd backend
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-dev.txt
.\venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- OpenAPI: http://127.0.0.1:8000/docs
- 健康检查: http://127.0.0.1:8000/health
- SQLite: `backend/data/tradesync.db`
- 表结构在启动时通过 Alembic 升级，基线只执行一次；已有库上线前先备份，见 [数据库迁移与恢复](../40-API与数据/数据库迁移.md)。

## 前端 Studio Admin

```powershell
cd frontend
copy .env.local.example .env.local
npm install
npm run dev -- --hostname 0.0.0.0 --port 3000
```

- 本机地址: http://127.0.0.1:3000
- 局域网访问: 使用运行机器的局域网 IP，例如 http://192.168.x.x:3000
- 登录页: http://127.0.0.1:3000/auth/v2/login
- API 地址通过 `NEXT_PUBLIC_API_BASE_URL` 配置，默认 `http://127.0.0.1:8000/api/v1`。

局域网电脑访问时，如果浏览器和前端不在同一台机器，请把 `.env.local` 中的 API 地址改成运行后端电脑的局域网 IP，例如：

```text
NEXT_PUBLIC_API_BASE_URL=http://192.168.31.116:8000/api/v1
```

## 测试

```powershell
cd backend
.\venv\Scripts\python.exe -m pytest -q tests
cd ..\frontend
npm run build
```

后端测试覆盖：EA V2.1 兼容、V2.2 同步轮次、批次幂等重试、缺失批次拒绝游标、停用账号拒绝同步、完整订单字段、同步日志安全口径。
