# 本地开发与联调

版本：2.0；状态：已生效；用途：提供单个本地开发环境的最小启动说明；维护人：集成负责人；依赖：新工作启动操作手册、迁移与接手指南；验收入口：`/readyz`、登录页和隔离质量门禁。

并行任务、三库隔离、端口登记和完整安装步骤以《新工作启动操作手册》第 5、7 节为准。本文不替代该操作手册。

## 1. 前置条件

- Node.js 22 与 npm。
- Python 3.11+。
- PostgreSQL 16 或兼容版本；开发、pytest、E2E 分别使用独立数据库。
- 从 `.env.example` 创建本机配置，禁止提交 `.env`、密钥、数据库口令和认证状态。

前端只使用 npm 与 `package-lock.json`。不要新增 pnpm 锁文件，也不要复制其他 worktree 的 `node_modules`、`.venv` 或 `.next`。

## 2. 安装

在仓库根目录执行：

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt -r backend/requirements-dev.txt
cp -n backend/.env.example backend/.env
cp -n frontend/.env.local.example frontend/.env.local
cd frontend
npm ci
cd ..
```

将 `backend/.env` 的 `TRADESYNC_DATABASE_URL` 指向本任务的 `tradeez_dev_*` PostgreSQL 数据库。手工开发时，`frontend/.env.local` 的 API 地址必须指向浏览器实际可达的后端，例如同机开发：

```dotenv
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

如果从另一台设备访问前端，不能使用该设备自己的 `127.0.0.1` 连接开发机后端；应另行使用开发机局域网地址并核对 CORS。

## 3. 启动

后端终端：

```bash
cd backend
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

前端终端：

```bash
cd frontend
npm run dev -- --hostname 127.0.0.1 --port 3000
```

检查：

- 就绪检查：<http://127.0.0.1:8000/readyz>
- OpenAPI：<http://127.0.0.1:8000/docs>
- 登录页：<http://127.0.0.1:3000/auth/v2/login>

开发测试模式启用后验证码为 `123456`，不会真实发送短信或邮件；生产环境禁止测试验证码。

## 4. 验证

静态门禁需要显式的独立 `tradeez_test_*` 数据库，浏览器门禁需要空的独立 `tradeez_e2e_*` 数据库：

```bash
./scripts/quality/static.sh
./scripts/quality/e2e.sh
git diff --check
```

不得把测试指向共享开发库或生产库。测试结果只证明执行时的提交，命令、提交、通过数和未执行项必须写入 Issue/PR。
