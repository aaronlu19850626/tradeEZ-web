# 模拟期货测试数据

版本：1.0；状态：本地测试数据已生成。

## 1. 用途

为账户、交易总览和交易记录提供人民币 CTP 测试数据，验证币种、市场、品种、日期、方向、结果和图表响应。

## 2. 账户

| 账户 | 登录号 | 平台 | 币种 | 市场 | 交易数 |
|---|---|---:|---|---|---:|
| `Sim-CTP-Commodity-A` | `990000001` | CTP | CNY | 国内 | 5,000 |
| `Sim-CTP-Financial-B` | `990000002` | CTP | CNY | 国内 | 5,000 |

时间范围：`2024-09-01` 至 `2026-08-31`。

## 3. 数据特征

- 共 10,000 笔已平仓交易，20,000 条开平仓成交。
- 商品账户覆盖 `RB / CU / AU / AG / RU / I / MA / TA / SC`。
- 金融账户覆盖 `IF / IH / IC / IM / T / TF / TS`，并包含部分重叠品种。
- 使用国内期货交易时段、周末和主要节假日规则。
- 使用品种真实量级的合约乘数、最小变动价位、手续费和手数范围。
- 覆盖日内、隔夜和数日持仓，止盈止损字段包含多种组合。
- 资金快照初始权益为 `1,000,000 CNY`，期末权益按实际净盈亏生成。

## 4. 执行命令

```bash
cd backend
.venv/bin/python scripts/seed_simulated_futures.py --dry-run
.venv/bin/python scripts/seed_simulated_futures.py --commit --reset
```

`--reset` 只删除上述两个固定登录号关联的数据，不影响 MT5 账户。

## 5. 数据验证

已核对：

- 两个账户均为 `platform=ctp`、`account_currency=CNY`、`market_profile=cn`。
- 每个账户 5,000 笔交易，共 10,000 笔。
- 日期范围覆盖 2024-09 至 2026-08。
- 商品账户净盈亏约 `1,213,507.60 CNY`。
- 金融账户净盈亏约 `2,397,006.40 CNY`。
- 可通过 `market_profile=cn`、`currency=CNY` 和账户范围筛选核对。
