# Setup 与 Playbook

迁移 `0010_playbooks` 增加用户独立的 Setup 和 Playbook 版本。Setup 包含名称、说明、适用品种、方向范围及启停状态；同一用户下名称唯一。

每个 Setup 最多有一个可修改草稿。发布后版本不可修改，再次编辑会从最新版本复制出下一版草稿。停用 Setup 保留历史版本，但不能发布新版本。

Playbook 包含市场环境、关键位置、触发条件、失效条件、风险约束、持仓管理、退出原则和禁止事项。规则支持分组、检查时点、是非／数值／选项／文本回答、人工／确定性评估、关键规则、是否允许不适用及权重。关键规则不能同时设为可不适用，选项规则至少两个选项。

页面：`/dashboard/playbooks`。接口位于 `/api/v1/my/setups`、`/api/v1/my/setups/{id}/draft`、`/api/v1/my/playbook-versions/{id}` 及发布接口。所有读写按当前用户隔离。

迁移 `0011_review_evaluations` 已支持把已发布版本关联到复盘，逐条记录 PASS、FAIL、UNKNOWN、N/A 和证据。系统计算评价完整度、证据覆盖率、执行分、合规结论及关键违规；覆盖率未达到 100% 时不产生正式执行分。评价每次保存都会保留历史快照。已关联规则但评价不完整时，复盘不能提交为已完成。

完整订单列表和复盘汇总会显示 Setup、Playbook 版本、评价完整度、覆盖率、执行分及关键违规。分析接口及页面支持按 Setup 和执行评价状态筛选，并按模型汇总交易数、净收益、胜率、已评分数量和平均执行分；未关联模型单独统计，不与已分类模型混合。
