# SOP v1.03 服务端对齐记录

后续更新：独立 Trade 落库、反转拆分和 SQL 分页已完成本轮实现，当前 54 项测试通过。以下保留接口对齐阶段记录，生命周期的最新行为及限制以 [交易生命周期](交易生命周期.md) 为准。

契约来源：[TradeEZ-SOP数据同步接口说明.md](TradeEZ-SOP数据同步接口说明.md)，2026-09-18 15:25 EA 基线。旧版 API 文档中的开仓时间游标已被本契约替代。

## 已实现

| 项目 | 服务端行为 |
|---|---|
| 七个 POST 接口 | 接受文档中的最小请求；成功统一 HTTP 200，业务错误返回非 2xx |
| HMAC | 对原始 UTF-8 body 与请求头时间文本验签，时间窗口 ±300 秒；新生成的账户 Key 必须签名 |
| 游标 | 数字 UTC 秒；查询额外声明 cursor_basis=out_deal_time。只允许已持久化的 entry=OUT 的 deal_time 推进，且单调不回退 |
| 成交重传 | 账号登录号 + ticket 幂等 upsert；整个请求一个事务；上传不隐式推进游标 |
| 无批次标识 | 不要求 batch_id、instance_id、总批数；无法证明完整批次数，不虚构批次回执。无新数据时 EA 不提交游标，未确认的查询轮次不代表同步失败 |
| 扩展批次协议 | 保留可选批次校验；其游标也统一为 OUT deal_time，不允许继续提交旧 open_time |
| 原始类型 | 保存非 BUY/SELL 的 MT5 type；归并时不把它当作买卖方向 |
| 数值 | 拒绝 NaN/Infinity；标识按 SQLite 有符号 64 位整数保存，超出范围明确 400。网页超过 2^53−1 的标识以十进制字符串返回 |
| 账户快照 | 同账号、同 UTC 秒、相同内容可重传；不同内容返回 409，整批回滚 |
| 参数快照 | 接受六组共 55 个字段；允许初始化、手动重发和迟到快照；同账号同秒相同内容幂等，不同内容 409。没有远程参数下发 |
| 元数据 | 最小心跳不覆盖已有币种/券商/时区；没有提供的 EA 版本保持未知。账户登录号在当前库全局唯一，不支持不同券商同号同时绑定 |
| 持仓视图 | 按真实 IN deal_time 确定开仓时间，包含开仓佣金，处理 OUT_BY；部分平仓保留剩余数量。缺开仓、数量冲突、非买卖类型与反转显示待核对，不混入已结束状态 |
| 探针 | 调整仓位选择与提交游标为 OUT 时间；已编译，不修改或挂载主策略 EA |

配置快照没有实例身份，同秒不同配置不能可靠分辨属于哪个图表，因此返回冲突而不任意覆盖。心跳接收时间只表示最近收到数据，不用五分钟阈值判定离线。

## 升级与本机使用

本次没有数据库结构迁移、没有重置实际库游标或清理历史成交。旧开仓游标保留为下一次查询起点，新的主 EA 按平仓时间包含式补传；已经丢失或从未上传的历史仍受客户端 7 天/向前 30 天窗口约束，不能由服务端凭空恢复。不要混用仍按开仓游标运行的旧 EA 二进制。

本机地址与参数见 [EA 本机接入](EA本地配置.md)。Inp_RequestTimeoutMS 使用 800；当前主 EA 会限制在 200–800ms。Inp_AlignIntervalHours 没有实际校准接口，不列为有效同步配置。网页 3000，API 8000；跨电脑需另行启用 HTTPS 可达地址。
