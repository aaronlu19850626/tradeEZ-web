# 账户配置进度

## 已交付

- 账户列表进入“账户配置”，可编辑名称、券商服务器、币种、IANA 服务器时区。清空可选字段会真正保存为空，币种统一大写。
- 绑定时必须选择同步开始日期，使用当天 00:00:00 UTC；后端要求显式传入 sync_start_time，拒绝布尔、非整数、负数和未来时间。旧账户的零起点继续兼容。
- 新账户开始同步前可以调整起点。已有成交、游标或同步轮次时，普通 PATCH 拒绝变更起点（409），不会偷偷重置数据。
- EA 初始游标读取 max(last_sync_time, sync_start_time)。无新增成交的确认允许确认该起点；超出起点的游标仍要求已存在对应 OUT 成交。写入和配置修改使用同一数据库事务锁，避免并发覆盖。
- 完整交易与待核对数量、最新平仓成交时间、首次成功同步状态可见。获取账户列表时刷新已变更生命周期。
- EA 参数模板支持填写并记住服务端 Origin。只在当前浏览器保存地址，不保存密钥；不自动访问所填地址，也不修改 EA。拒绝包含凭据、查询串或 /api/v1 的地址。
- 重新生成密钥增加影响确认。停用提示明确仅停止同步，不停止 MT5 交易。
- EA 配置快照支持搜索，过期提醒，接口响应递归隐藏凭据字段。已保存的原始快照不改写。

## 账户备注与配置冲突保护

- 迁移 `0007_account_notes` 新增 `notes` 和 `config_revision`，已有账户默认无备注、版本为 0。绑定时可填写备注；账户配置可修改、清空；列表显示前两行，配置面板可查看全文。
- 备注最多 2000 字符，去除首尾空白，保留内部换行，空字符串保存为 null。仅账户所有者可读取、修改，不下发至 EA。重同步保留，账户删除一并清除。
- 编辑器和启停操作携带 `expected_revision`，事务内检查配置版本；实际变更后递增，内容完全相同不递增。旧页面保存返回 409 并保留草稿，可点击“读取最新配置”（覆盖未保存草稿前确认）。同步心跳不会导致配置冲突；重同步修改起点会递增版本。
- 修改备注必须提供版本。为兼容旧客户端，未修改备注的旧 PATCH 仍允许不带版本，但会递增版本使当前编辑器识别变更；第三方客户端应升级为带版本的更新方式。
- 备注或配置发生变化会使旧重同步/删除预览失效，防止删除刚更新的资料。未填写券商服务器的历史账户可以独立补充备注，无需猜测服务器名。
- 82 项后端测试通过，覆盖归属隔离、长度与类型校验、清空、并发冲突、旧草稿不覆盖新内容、重同步保留、维护预览失效和删除。
