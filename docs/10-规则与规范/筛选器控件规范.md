# 筛选器控件规范

版本：v1；状态：已确认。

## 1. 基线组件

单选下拉控件以 `SelectSingleControl` 为全局基线：

```ts
import { SelectSingleControl } from "@/components/filters";
```

后续新增的筛选控件必须与它保持一致的视觉和交互。

## 2. 视觉规范

- 触发器：标准描边按钮，高度 8（Tailwind `h-8`），文字使用 `text-sm leading-none`。
- 初始未选中：普通字重、次要前景色；选中后：文字加粗、主前景色。
- 右侧统一使用 `ChevronDown` 小号箭头，颜色降低透明度。
- 下拉面板：圆角 `rounded-lg`，内边距 `p-1`，宽度与内容或触发控件合理对齐。
- 选项：`text-sm leading-normal`，上下内边距 `py-1.5`，左侧预留 16px 对勾占位。
- 选中项：不加背景色，仅在左侧显示主色对勾。
- 悬停项：使用系统菜单悬停背景。

## 3. 交互规范

- 点击触发器或箭头打开下拉；选择后关闭。
- 单选控件必须有明确默认值；无法确定默认值时使用占位符。
- 弹层默认与触发控件同一侧对齐，可通过 `align` 配置。
- 加载、禁用和筛选变化期间，控件继承外层状态，不单独维护视觉异常。

## 4. 后续控件清单

- 单选 Select
- 单条件多选 Select
- 日期范围选择
- 复杂多条件 Select

以上控件在实现前先复用本基线组件和规范，新设计需保持字号、行距、对勾、悬停背景和弹层对齐一致。
