# 全局筛选器与交互控件规范

版本：v2；状态：已确认，前端开发强制遵守。

## 1. 全局入口

共享筛选控件统一从以下入口导入：

```ts
import {
  AccountScopeMenu,
  RangeControl,
  SelectMultiConditionControl,
  SelectSingleControl,
} from "@/components/filters";
```

底层实现位于 `frontend/src/components/filters/`，业务页面不得复制一套选择器、日期选择器或筛选面板。

## 2. 主控件基线

所有筛选主控件复用同一视觉：

- 触发器使用全局 `Button variant="outline" size="sm"`，高度 `h-8`。
- 文案使用 `text-sm leading-none`。
- 未选择 / 默认条件：`font-semibold text-muted-foreground`。
- 已选择条件：`font-semibold text-foreground`。
- 右侧统一使用 `ChevronDown`；展开后切换为 `ChevronUp`。
- 主控件宽度允许随文本自适应；面板内多列选项必须保持等宽等距。

## 3. 下拉面板基线

- 面板使用 `rounded-lg`，内边距 `p-1`，右侧控件使用 `align="end"` 对齐。
- 单选组使用 `RadioGroup`，多选组使用 `Checkbox`。
- 单选和多选的行高、上下内边距必须一致。
- 选中项不加背景色，只在左侧显示主色对勾；悬停项使用系统菜单背景。
- 分区标题使用小号灰色文本，分区之间使用分隔线。
- 底部使用标准 `Button`：左侧“关闭”，右侧“确认”。

## 4. 控件类型

### 4.1 单选 Select

- 组件：`SelectSingleControl`
- 必须有明确默认值；无法确定时显示占位符。
- 选项只作用于当前字段。

### 4.2 单条件多选 Select

- 组件：`AccountScopeMenu`
- 全选或未选择时，后段条件显示“全部”，表示无需条件。
- 多选回写：1 项显示全名；2 项显示“名称1/名称2”；超过 2 项显示“名称1/名称2 等N项”。

### 4.3 复杂多条件 Select

- 组件：`SelectMultiConditionControl`
- 支持 `mode: "single" | "multiple"` 分组。
- 面板左侧显示条件名称，右侧显示当前条件的单选项或复选项。
- 同一品种聚合为一行，账户名称显示在品种下方；多个账户名称使用分割线隔开，列表使用固定高度并在面板内滚动。
- 底部左侧提供“清空条件”，中间显示“条件名称：条件值”并支持逐项删除；“全部”不作为已选条件展示，右侧提供“关闭 / 确认”。
- 触发区显示“筛选器 · 无”或“筛选器 · 条件摘要”。
- 当账户范围同时包含国内与外汇市场时，增加“市场”单选；聚合视图必须收敛到单一市场。

### 4.4 日期范围

- 组件：`RangeControl`
- 左侧显示日历图标；有日期时显示完整范围。
- 清除日期后显示“全部日期”，表示请求不携带日期条件。
- 面板内使用两个独立 `DatePickerField`，支持月份和年份下拉。
- 快捷区包含：全量日期、今日、本周、上周、近30日、年初至今。
- 最近周期包含：近12个月（6个一列，两列）和近6个季度（单列）。
- “全量日期”表示显式全范围条件；“全部日期”表示无日期条件，两者不可混用。
- 开始日期不得大于结束日期。

## 5. Tab / Toggle

- 视图切换统一使用全局 `ToggleGroup`。
- 轨道使用浅灰背景；选中项使用 `primary-soft`、主色文字和 `font-semibold`。
- 未选中项使用次要文字色；不得用白色背景伪装选中。

## 6. 数值与分页

- 金额、数量和图表统计值统一使用全局 `@/lib/format-numbers`，业务模块不得自行实现 K 值逻辑。
- 金额、数量绝对值达到 10,000 时统一使用 K 值，默认保留一位小数，例如 `-$12.3K`、`62.4K`。
- 精确金额固定两位小数并带币种符号；默认币种为 USD，账户原币必须显式传入。
- 分页页码输入框必须与相邻图标按钮等高，并覆盖全局 Input 的 `min-height`。
- 分页操作保持局部刷新，不触发整页重载。

## 7. 加载与禁用

- 初始化、筛选重载或大数据汇总期间，筛选区必须禁用并进入 `aria-busy + inert`。
- 大数据汇总时显示浮动加载提示；小数据不显示提示。
- 加载更多只更新局部列表，并显示旋转加载图标。

## 8. 适用规则

后续模块遇到筛选、日期范围、单选、多选、复杂条件和视图切换场景，必须先复用本规范中的全局组件；如需新增变体，先补充规范并完成评审。
