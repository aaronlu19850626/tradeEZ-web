# TradeEZ 组件库治理规范

版本：1.0；状态：已生效；用途：沉淀可复用 UI 和交互模式；维护人：前端负责人；验收入口：设计系统页面。

## 分层

- `src/components/ui/`：shadcn/Radix 基础语义控件，保持上游来源稳定，不为单个页面直接改造。
- `src/components/shared/`、`src/components/data-table/`、`src/components/filters/` 和领域目录：TradeEZ 业务模式和统一状态组件。
- 设计系统页面：组件目录、状态演示和可访问性验收入口。

## 提升条件

组件在两个模块复用，或拥有统一尺寸、状态、键盘行为、主题和国际化要求时，才提升为共享业务组件。单页面专用组件留在所属路由目录。

## 组件交付要求

必须定义默认、hover、active、focus-visible、disabled、loading、empty、error、success、中文、英文、Light、Dark、390/768/1024/1440px 行为。图标使用注册表，不用文字、emoji 或近似图标替代。
