# TradeEZ 全局样式与交互规则

版本：1.1；状态：已确认，后续模块默认继承。

## 使用方式

这是后续前端模块的全局执行规则。模块设计文档只补充本模块特有的例外，不重复定义颜色、字号、面板、表格、按钮和提示组件。

组件、状态、尺寸和响应式的完整执行标准见 [UI 规范](UI规范.md)，后续前端开发必须同时遵守两份文档。

## 工作台基线

- 保留现有 Light / Dark 双主题，并以当前语义 Token 控制内容区、侧栏和操作色。
- 全局界面与数字使用 Geist Sans，中文回退苹方/微软雅黑；金额、指标和表格数字继续启用等宽数字特性。
- 保留原有页面框架、导航、侧栏折叠、Light / Dark 切换和布局能力；暂不新增未评审的主题包、字体或样式配置。
- 品牌名称使用 TradeEZ；顶栏标语为“TradeEZ · 让复盘更简单，让进步看得见”，品牌名使用轻量渐变强调，整体保持克制。
- 展开侧栏宽度 16rem，收缩侧栏宽度 2.75rem；收缩时 Logo 无背景色并水平居中，菜单图标和点击区域保持可识别尺寸。
- 顶栏状态区与语言切换按钮等高；竖向分割线必须垂直居中。

## 颜色语义

| 场景 | 视觉规则 |
|---|---|
| 普通操作 | 使用默认中性文字，悬停使用前景色或轻微背景变化 |
| 主操作 | 使用 TradeEZ 紫色，白色文字 |
| 高风险操作 | 使用低饱和黄色，例如重置交易、重置密钥 |
| 严重/不可逆操作 | 使用低饱和红色，例如物理删除 |
| EA 同步中 | 高级低饱和绿色底色、绿色边框、绿色状态点，文案“同步中” |
| EA 未检测到 | 高级低饱和红色底色、红色边框、红色状态点，文案“未检测到 EA” |
| 交易数量 | 使用正文黑色/前景色，不使用品牌紫色；品牌紫色保留给可点击链接和主操作 |
| 盈亏结果 | 仅在表达盈亏语义时使用盈亏色；缺失数据使用 N/A，不用 0 代替 |

## 面板和指标卡

- 卡片使用 `card`、`border` 和阴影等语义 Token 形成层次，不写死白色背景。
- 卡片标题栏默认纵向内边距约 12px；标题与辅助说明尽量水平排列，减少空白高度。
- 指标卡标题旁必须提供 `?` 提示按钮；提示内容说明指标口径、范围或数据来源。
- 指标数值默认 30px 左右、字重 600 以上，并向标题方向靠近；单位使用较小的中性色文字。
- 说明文字、标题和数值通过字号、字重、颜色区分，不整卡使用高饱和颜色。
- 总览内 Recharts 图表统一左侧标尺规范：纵轴宽度 56px、图表左边距 -4px、刻度字号 10px、刻度间距 3px，避免各图表左侧留白不一致。
- 总览内逐笔散点统一使用小尺寸圆点（约 6px）和 0.5px 同色系深色描边，避免密集数据糊成色块。

## Tooltip

- 所有 Tooltip 统一使用最大宽度 256px。
- 内容超出宽度自动换行，左对齐，行高约 1.6；不使用过宽的单行提示。
- Tooltip 由统一组件提供，模块不得自行复制一套宽度和排版。
- 弹窗打开时不得自动展开内部 Tooltip；初始焦点落在弹窗容器，用户通过鼠标悬停或键盘 Tab 主动查看提示。

## 数据表格

- 表头使用浅紫灰背景，标题加粗，表头高度约 40px。
- 表格标题、说明和刷新操作在同一标题栏内；冗余说明不放在表格底部。
- 单元格按照主数据、辅助数据、状态标签分层；时间、数量和金额保持清晰的等宽数字表现。
- 核心操作放在行内；普通操作中性，高风险黄色，严重操作红色。
- 可点击的账户名称使用链接样式，点击进入改名；不再额外提供重复的“改名”按钮。
- 表格支持正常内容高度，不用固定高度隐藏操作；窄屏允许局部横向滚动。

## 交互可发现性

- 所有可点击的 `button`、链接、菜单项、文件选择区域和按钮角色元素统一显示手型光标。
- 禁用控件不显示手型，并保持明确的禁用对比度。
- 危险操作使用居中确认模态框；不使用右侧抽屉承载核心操作。
- 新增、编辑、重置和删除等状态必须提供成功、失败、加载和 N/A 表现。

## 开发检查

每个模块完成前端 mock 后，检查：颜色语义、Tooltip 最大宽度、按钮高度、卡片标题栏高度、表头高度、鼠标手型、键盘焦点、空状态、N/A 和窄屏显示。通过用户确认后才进入后端接口开发。
# 侧栏与主面板尺寸修正

- 主体内容桌面两侧留白：lg 为 40px，xl 为 48px；保持随侧栏收缩扩大。收缩时底部个人菜单按钮居中、去除内部偏移，隐藏用户名和更多图标，只保留居中头像作为菜单入口。

- 最新调整：展开菜单宽度 224px，收缩保持 72px；Logo 右侧展示“让复盘更简单，让进步看得见”，采用淡紫到冰蓝渐变字，小屏隐藏以避免挤占顶部操作。侧栏与占位宽度使用一致的 320ms 缓出动画，内容区持续自适应宽度；系统减少动态效果偏好下关闭动画。

- 顶部取消广告语，仅保留 Logo 和 TradeEZ 品牌名；主内容与深紫框架交界处左上圆角进一步缩小为 rounded-md。

- 最新框架：顶部固定 64px，与菜单同为深紫色；收缩按钮在 Logo 左侧，Logo 常驻顶部、位置和尺寸不随菜单改变。侧栏从顶部栏下方开始，工作区独立滚动。主面板仅保留左上小圆角，底部直角。此规则覆盖此前顶部留白和收缩 Logo 规则。

- 桌面主面板使用 rounded-xl 小圆角及顶部留白，不依赖用户保存的侧栏布局偏好；顶部栏继承主面板圆角。侧栏与主面板交界不使用边框或外阴影，避免出现白色分割线。
- 收缩侧栏基础宽度为 72px，Logo 为 32px、透明背景并水平居中；不得为扩大内容区而压缩至 44px。
- 桌面侧栏收缩时，顶部栏、工作区及页面根容器解除居中最大宽度限制，卡片和表格随可用空间扩展；保留正常内边距。展开时恢复原布局宽度。不要扩大弹窗或 Tooltip 的宽度。
