# 质量门禁与并行运行规范

版本：1.0；状态：已生效；用途：统一静态检查、浏览器回归和并行环境；维护人：技术负责人；验收入口：质量脚本和 CI。

## 门禁

- `./scripts/quality/static.sh`：后端 pytest、前端 TypeScript、Biome、生产构建和 `git diff --check`。
- `./scripts/quality/e2e.sh`：启动状态检查、Playwright 桌面/平板/移动回归和截图/trace 证据。
- `./scripts/quality/check.sh`：本地完整门禁；可用 `SKIP_E2E=1` 只执行静态门禁。

## 并行隔离

- 每个任务使用独立 worktree、端口、数据库、`.env` 和 Playwright 状态目录。
- `TRADESYNC_DATABASE_URL` 与 `TRADESYNC_TEST_DATABASE_URL` 不得指向共享开发库。
- 认证文件、截图、报告和日志放在任务目录或忽略目录，不提交真实数据。
- 端口通过 `TRADEEZ_BACKEND_PORT`、`TRADEEZ_FRONTEND_PORT` 和 `TRADEEZ_BASE_URL` 配置；默认仍为 8000/3000。
