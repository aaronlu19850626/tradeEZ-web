# 模块页面布局约束

版本：1.1；状态：已生效

状态：已审批并生效。交易总览、交易记录和交易账户主页面均已完成 A/B/C/D 布局迁移。

## 1. 目标

后续所有模块主页面统一使用同一套页面骨架，保证：

- 标题栏和主体区域背景连续。
- 标题、主体内容、右侧操作区使用统一对齐基准。
- 吸顶状态可预测，不使用负 margin、背景补丁或模块私有定位方案。
- 内部框架面板具有固定的四周内边距，保证跨模块视觉一致。
- 页面不需要为单个模块重复定义标题字号、操作按钮尺寸和间距。

## 2. 页面结构

所有模块主页面固定由以下四层组成：

```text
A 页面根容器
├── B 模块标题栏
│   └── D 标题栏内容容器
└── C 模块主体
    └── 模块内部业务面板
```

### A：页面根容器

- 占满工作区可用宽度。
- 无内边距。
- 无外边距。
- 不提供额外的视觉背景和边框。
- 不负责标题栏或主体内容的最大宽度限制。

### B：模块标题栏

- 位于 `A` 的第一个内容区域。
- 与主体 `C` 使用完全相同的背景色。
- 无外边距。
- 固定内边距：
  - 上下：`20px`
  - 左右：`40px`
- 默认不显示底部边界线。
- 页面滚动进入吸顶状态后：
  - 整条标题栏吸附在滚动容器顶部。
  - 使用实色背景遮挡主体内容。
  - 底部显示 `1px` 细线。
  - 细线颜色使用 `foreground/35`，不得写死黑色。
- 离开吸顶状态后恢复透明背景和无边界线状态。

### D：标题栏内容容器

- 仅承载标题、说明和右侧操作区。
- 无内边距。
- 无外边距。
- 使用水平 Flex 或 Grid 布局。
- 内容垂直居中。
- 左侧标题与右侧操作区分别使用 `B` 的左右内边界对齐。

### C：模块主体

- 与标题栏 `B` 使用相同背景色。
- 无边框。
- 固定内边距：
  - 顶部：`0`
  - 左右：`40px`
  - 底部：`20px`
- 标题栏 `B` 的底部内边距负责与主体内容形成垂直间距。
- 主体内容不得再次增加页面级顶部内边距。

## 3. 标题规范

模块主标题统一使用：

| 属性 | 规范 |
|---|---|
| 字号 | `24px` |
| 行高 | `32px` |
| 字重 | `600` |
| 颜色 | `foreground` |
| 对齐 | 与主体 `C` 的左内边界对齐 |

模块不得自行使用 `text-3xl`、`text-4xl` 或其他字号覆盖主标题。

如标题包含说明文字，说明文字放在标题右侧或标题下方，不得改变主标题字号和基线。

## 4. 标题栏右侧操作区

右侧操作区统一遵守以下规则：

### 4.1 排列

- 操作区位于 `D` 的最右侧。
- 操作内容垂直居中。
- 操作项之间水平间距固定为 `8px`。
- 最右侧元素与主体 `C` 的右内边界对齐。

### 4.2 按钮

- 必须使用全局 `Button` 组件或其标准语义变体。
- 默认高度：`32px`。
- 同一操作区内按钮高度必须一致。
- 一个模块标题栏最多保留一个主操作按钮。
- 主操作使用 `default` 变体。
- 次级操作使用 `outline` 或 `ghost` 变体。
- 图标按钮必须提供 `aria-label`。
- 禁止为单个模块自绘按钮或修改 Button 的核心尺寸。

### 4.3 菜单和选择器

- 账户、范围、视图等选择器使用全局标准 Select 或 DropdownMenu。
- 选择器高度必须与同组按钮一致。
- 选择器宽度根据内容自适应，不设置无依据的固定宽度。

## 5. 内部框架面板

主体 `C` 内的框架面板统一遵守：

- 默认背景：`card`
- 默认圆角：轻度圆角，建议 `8px`
- 固定四周内边距：`20px`
- 面板之间使用固定间距，不使用依赖单个子元素的 margin 拼凑布局
- 面板内部标题、列表、分隔线和底部操作区均以面板的 `20px` 内边界为基准
- 面板不得嵌套 Card

## 6. 响应式规则

- 桌面端严格执行本文固定尺寸。
- 移动端允许将主体左右内边距降为 `16px` 或 `24px`，但必须保持标题和主体左边界一致。
- 标题栏吸顶、背景遮挡和底部细线规则在移动端与桌面端一致。
- 操作区在窄屏允许换行，但不得压缩成不可读按钮。

4. 每个模块完成后执行 TypeScript、Biome、Playwright 和生产构建。
