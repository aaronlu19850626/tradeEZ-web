# 项目概览

TradeEZ 将交易平台原始成交和账户快照同步到服务端，形成可追溯的账户、交易、统计、计划和复盘数据。产品目标是帮助交易者核对事实、分析表现、执行计划并持续复盘；系统不替用户执行交易，也不承诺收益。

## 系统组成

```text
交易平台/连接器
  → FastAPI 同步与业务 API
  → PostgreSQL 原始事实和业务投影
  → Next.js 交易工作台
  → 统计、计划、复盘和 AI 辅助
```

当前仓库主要目录：

| 目录 | 责任 |
|---|---|
| `frontend` | 登录、Dashboard 页面、设计系统和浏览器测试 |
| `backend` | API、业务域、数据库访问、迁移和后端测试 |
| `connectors` | MT5 及其他平台适配器 |
| `scripts` | 质量门禁、数据库和发布辅助脚本 |
| `docs` | 当前有效的长期规则和规格 |

## 产品边界

- TradeZella 用于研究核心结构、交互、状态和业务流程；TradeEZ 使用自己的品牌、组件、文案和产品规则。
- 用户数据必须按用户和账户隔离；原始交易事实与人工复盘资料分离。
- AI 只能在用户授权范围内提供整理、摘要和分析，不能下单、修改账户或覆盖用户原文。
- 当前能力和模块权威状态见[模块目录](../20-产品与研究/模块目录.md)。
