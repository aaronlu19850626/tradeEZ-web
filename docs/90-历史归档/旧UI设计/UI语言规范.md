# 界面语言约定

当前产品统一使用简体中文，尚未提供全站语言切换。新增配置入口、按钮、选项、提示、错误及无障碍标签均应使用中文。

- 同步凭证统一称为“同步密钥”；账号标识称为“MT5 登录号”；broker server 显示为“券商服务器”。
- EA 原始参数名、协议字段、网址、币种代码、时区标识、品牌和字体名称保留原文，参数标识应配中文说明；复制到 EA 的配置不得翻译或修改。
- EA 参数说明集中维护于 `frontend/src/app/(main)/dashboard/accounts/_components/ea-settings-labels.ts`，来源为 v1.03 接口说明的 6 个分组、55 个字段。未知字段仍展示原值，并标注为扩展参数。
- 后续如增加多语言，应统一接入语言资源、语言选择与持久化，并覆盖页面、校验错误、日期数字格式及无障碍文案，避免仅翻译菜单或单独开放某个模块的语言切换。

本次已统一界面设置、主题提示、侧栏入口、账户连接标签与密钥文案，并将 EA 参数快照改为带中文说明的分组列表，支持中英文参数搜索。现有账户尚无参数快照，真实快照展示需 EA 上传后确认。
