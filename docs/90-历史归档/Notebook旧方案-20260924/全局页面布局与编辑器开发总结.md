# 全局页面布局与编辑器开发总结

版本：1.0；状态：已生效。

## 1. 总结范围

本文总结以下已完成工作：

- 交易总览、交易记录、交易账户和 Notebook 的页面布局统一。
- 页面标题栏、主体区和查询栏的吸顶规则。
- 首页模块的共享布局组件和 CSS 约束。
- Lexical Notebook 编辑器的实现、图片交互和回归范围。
- 编辑器代码结构、文档入口和后续扩展边界。

## 2. 全局页面布局

所有模块主页面统一采用 A/B/C/D 骨架：

```text
A 页面根容器
├── B 模块标题栏
│   └── D 标题栏内容
└── C 模块主体
    └── 业务面板
```

### 2.1 A 页面根容器

- 占满工作区宽度。
- 无页面级内外边距。
- 不承担标题、主体或最大宽度限制。

### 2.2 B 模块标题栏

- 使用共享组件 `StickyPageHeader`。
- 背景与主体一致。
- 上下内边距 `20px`，左右内边距 `40px`。
- 进入吸顶状态后使用实色背景，避免主体内容穿透。
- 默认模块标题栏不强制显示底部线；交易总览和交易记录由查询栏控制底线。

### 2.3 C 模块主体

- 顶部内边距为 `0`。
- 左右使用 `40px`。
- 底部使用 `20px`。
- 内部框架面板使用 `card` 背景、轻圆角和固定内边距。
- 不允许页面级主体再次增加顶部 padding。

### 2.4 D 标题栏内容

- 只承担标题、说明和右侧操作。
- 无额外内外边距。
- 与主体左右边界对齐。
- 标题统一为 `24px / 32px / 600`。
- 右侧按钮和选择器使用全局标准组件。

## 3. 吸顶规则

### 3.1 普通模块

- 页面标题栏吸顶在滚动容器顶部。
- 吸顶时标题栏显示背景和底部细线。
- 离开吸顶状态后恢复透明背景。

### 3.2 交易总览与交易记录

- 页面标题栏保持不透明，但不显示底部线。
- 全局查询栏吸附在标题栏下方。
- 查询栏吸顶后，在查询栏底部显示 `foreground/35` 的 `1px` 细线。
- 初始状态只显示标题栏和查询栏，不提前显示黑线。

### 3.3 交易记录全部视图

- 分页/范围标题栏、表格表头和内部滚动区组成同一个吸附组。
- 查询栏下方依次排列：
  - 页码与范围标题栏。
  - 表格表头。
  - 表格内部滚动区。
- 页面滚动和表格内部滚动均保持表头稳定。
- 每页仍为 `100` 条，表格视口限制为约 `20` 行高度。

### 3.4 Notebook

- 页面级标题栏使用共享 `StickyPageHeader`。
- 笔记内部标题栏不吸顶，避免和编辑器工具栏重叠。
- 编辑器工具栏固定在编辑器顶部区域。
- 图片编辑控件随图片编辑态显示，不参与页面级吸顶。

## 4. 共享组件

页面骨架：

- `frontend/src/app/(main)/dashboard/_components/sticky-page-header.tsx`

模块落点：

| 模块 | 文件 |
|---|---|
| 交易总览 | `frontend/src/app/(main)/dashboard/overview/_components/overview-page.tsx` |
| 交易记录 | `frontend/src/app/(main)/dashboard/trade-center/_components/trade-center-page.tsx` |
| 交易账户 | `frontend/src/app/(main)/dashboard/account-center/_components/account-center-page.tsx` |
| Notebook | `frontend/src/app/(main)/dashboard/notebook/_components/notebook-page.tsx` |

统一约束：

- 模块页面只负责业务内容和布局组合。
- 标题栏、按钮、输入框、表格、分页、Badge、Tooltip 和弹窗使用全局组件。
- 不嵌套 Card。
- 不用模块私有 CSS 覆盖全局 Button、Card、表格和主题 Token。
- 页面级吸顶行为集中在共享组件或模块明确登记的容器中。

## 5. Notebook 编辑器

### 5.1 技术栈

- Lexical。
- Next.js App Router + React 19。
- 客户端动态加载。
- Markdown / Lexical JSON 双存储。
- 全局设计 Token。

### 5.2 架构

```text
Notebook 页面
  -> notebook-editor.tsx 数据适配
  -> lexical-editor.tsx 动态入口
  -> lexical-editor-client.tsx 编辑器组合
     -> 工具栏
     -> 标签条
     -> 划词工具栏
     -> `/` 命令菜单
     -> 自定义节点
```

### 5.3 功能

- 标题、正文、列表、待办、引用、代码、分割线。
- 加粗、斜体、下划线、删除线和清除格式。
- 字体颜色、背景颜色、字号和对齐。
- 链接、表格、图片、分栏、公式和第三方嵌入入口。
- 撤销、重做、模板、标签和全屏。
- 自动保存、历史版本和回收站。
- 中英文切换和 Light / Dark 主题。

### 5.4 图片编辑

- 默认状态只显示图片。
- 单击图片进入编辑态。
- 点击外部或按 `Esc` 退出。
- 缩放和裁剪使用不同图标。
- 裁剪 scissors 图标按边旋转，方向与裁切区域一致。
- 裁剪手柄固定在边缘 `75%` 区域。
- 图片尺寸以未裁切基准宽高保存，裁剪比例独立保存。
- 编辑器禁用 Lexical 和浏览器右键菜单。

### 5.5 代码入口

- 动态加载：`frontend/src/components/editor/lexical-editor.tsx`
- 编辑器组合：`frontend/src/components/editor/lexical-editor-client.tsx`
- 工具栏：`frontend/src/components/editor/lexical-toolbar-controls.tsx`
- 划词菜单：`frontend/src/components/editor/lexical-floating-toolbar.tsx`
- `/` 菜单：`frontend/src/components/editor/lexical-slash-command-menu.tsx`
- 插入弹窗：`frontend/src/components/editor/lexical-insert-dropdown.tsx`
- 自定义节点：`frontend/src/components/editor/lexical-tradezella-nodes.tsx`
- 编辑器样式：`frontend/src/components/editor/lexical-editor.css`

## 6. 规范化结果

本次整理完成：

- 删除未使用的 Tiptap `markdown-editor.tsx` 和对应 CSS。
- 移除 Tiptap、表格扩展和图片缩放扩展依赖。
- 明确 Lexical 为 Notebook 唯一编辑器实现。
- Notebook 设计文档升级到 Lexical 口径。
- 模块页面布局约束从“待审批”升级为已生效版本。
- 新增本总结文档并纳入项目文档索引。
- 保留 Playwright 对页面布局、图片编辑和编辑器主流程的回归覆盖。

## 7. 质量门禁

整理后必须通过：

```bash
npx tsc --noEmit
npx biome check --write <changed-files>
npx playwright test tests/e2e/notebook-slash-menu.spec.ts --project=desktop
npx next build --webpack
```

模块页面布局相关还应覆盖：

```bash
npx playwright test tests/e2e/trade-center.spec.ts tests/e2e/trade-center-controls.spec.ts --project=desktop
```

## 8. 后续边界

- 不新增第二套编辑器实现。
- 不在 Notebook 页面内直接修改 Lexical 节点内部结构。
- 新编辑器能力进入 `frontend/src/components/editor`，页面只传业务数据。
- 外部附件上传接入后替换 Data URL，不改图片节点交互协议。
- 策略 Notes 复用同一编辑器接口。
- AI、语音、评论、协作和历史版本按独立能力设计，不耦合页面布局。
