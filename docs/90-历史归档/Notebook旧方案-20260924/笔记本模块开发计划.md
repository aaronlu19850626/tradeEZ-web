# 笔记本模块开发计划

版本：1.0；状态：待审批；阶段：前端 Mock 前。

## 1. 目标

从零重建 Notebook 模块，以 TradeZella 的 Notebook 为参考产品，复用已固化的 `LexicalEditor` 与 `components/notebook` 通用能力，按“先前端 Mock、经确认后后端”的门禁开发。

## 2. 参考产品观察（研究浏览器事实）

页面：`https://app.tradezella.com/tracking/notebook/:folderId(/:noteId)`。

### 2.1 页面信息架构

- 最外层：顶部全局条（菜单、账户范围、通知、个人菜单）。
- 左侧产品导航：窄条图标导航。
- Notebook 内部三栏：
  - 目录栏：系统文件夹与自定义文件夹，含计数、折叠、`New note`、`More options`、`Add folder`。
  - 笔记列表：日期分组、相对时间、`Show all N` 分批展开。
  - 编辑区：无选中时显示 `Select a note to view`，选中后显示笔记头和编辑器。

系统文件夹：`All notes`、`Favorites`、`Trade Notes`、`Daily Journal`、`Sessions Recap`、`Tags`、`Trash`、`My notes`、`Add folder`。

### 2.2 笔记编辑器

笔记头：`Share`、收藏星标、`More options`、保存状态、交易统计（`Net P&L`、`N trades · W% win rate`）。

工具栏从左到右：

1. `Write with AI`（暂不实现能力，保留入口）
2. `Enable speech to text`
3. `Templates`
4. `Tags`
5. 文本样式（Normal / Heading 1-3 / 列表 / 待办 / 引用 / 代码）
6. 字体族（如 `Arial`、`Courier New`）
7. 减小/增大字号
8. 行内样式（加粗、斜体、下划线、删除线）
9. 插入链接
10. 清除格式
11. 文字颜色
12. 背景颜色
13. 对齐
14. 插入节点（图片、表格、分割线等）
15. 右侧：撤销、重做、版本历史、全屏

模板下拉：`Daily Game Plan`、`All-in-One/Daily`、`Intra-day Check-in`、`See more templates`、`Manage Templates`；系统模板可插入，可进入模板管理。

版本历史：右侧抽屉/弹层，按时间倒序列出 `Saved version`，含 `Load more`、`Close`、`Restore this version`。

### 2.3 交互与状态

- 自动保存：笔记头显示 `Saving...` 与 `Last update: X ago`。
- 新建笔记、收藏、分享、更多操作、模板管理、标签、历史、导入导出（`Import/Export/Export as PDF/Export as Lexical`）是核心操作。

## 3. 复用资产

- `components/editor`：通用 `LexicalEditor`，含工具栏、标签、模板插入、划词菜单、`/` 命令、图片/表格编辑、全屏。
- `components/notebook`：通用 `TemplateManagerDialog`、`TemplateEditorDialog`、`VersionHistoryDialog`、`useTemplateManager`、`useVersionHistory`、模板与历史纯函数。
- `components/ui`、`components/filters`：标准控件与筛选器。

## 4. 数据模型（前端 Mock 契约）

```text
Folder
  id, name, systemFolder?, order, createdAt

Note
  id, folderId, title, markdown, lexicalDocument
  tags[], favorite, deleted
  revision, createdAt, updatedAt
  versions[]
  trade?: { tradeId, symbol, netPnl }
  dailyStats?: { netPnl, volume, commissions, netRoi, grossPnl }
  session?: { relatedNoteId? }

NoteVersion
  id, revision, markdown, lexicalDocument
  savedAt, label, source, author, contentHash

Template
  id, name, description, markdown, builtIn, scope, isDefault
```

## 5. 一期范围

### 5.1 纳入

- 三栏页面壳与响应式。
- 系统/自定义文件夹、计数、重命名、删除、新建文件夹。
- 笔记列表：日期分组、相对时间、分批展开、搜索、收藏、回收站。
- 新建/编辑/删除/恢复笔记；交易笔记关联交易；每日日志展示当日统计。
- 编辑器：复用 `LexicalEditor`，含工具栏、标签、模板、划词、图片/表格、全屏、语音输入。
- 模板管理：系统/用户模板、复制、编辑、设默认、删除、按范围选择。
- 历史版本：自动保存与快照分离、手动/离开/周期快照、只读预览、行级差异、恢复留痕。
- 标签：新建、筛选、多选、快速移除。
- 中英文、Light/Dark、键盘操作、加载/空/错误状态。

### 5.2 暂不纳入

- AI 写作、第三方嵌入、分栏、字体族高级能力（字体族保留下拉，能力按编辑器现状）。
- 分享、导入导出（保留入口，能力后置）。

## 6. 开发顺序

1. 数据契约与 Mock 数据（`_lib`）。
2. 页面壳与三栏布局。
3. 目录栏、笔记列表、筛选与回收站。
4. 编辑器接入与笔记头。
5. 模板管理与历史版本接入通用模块。
6. 状态与回归：`tsc`、`biome`、`next build`、Playwright。

## 7. 验收

- 与参考产品逐项对账的布局、图标、字体、间距、状态和弹层。
- 前端 Mock 全流程可用，中英文与主题正常。
- `tsc`、`biome check`、`next build --webpack` 通过。
- 新增 Playwright 用例覆盖：三栏导航、文件夹 CRUD、笔记 CRUD、模板、历史、标签、回收站、编辑器格式。
