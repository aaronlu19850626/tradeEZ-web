# 前端自主设计清单

版本：1.0；状态：执行中；用途：记录参考产品无法直接观察或不适用的自主 UI 设计，作为用户评审范围。

## 规则

1. 功能点实现前仍必须先通过研究浏览器观察 TradeZella 对应页面和交互。
2. 无法观察到、参考实现不完整或与 TradeEZ UI 规范冲突时，不暂停开发。
3. 自主设计必须优先使用 TradeEZ 已有 Token、标准控件、布局和交互规则。
4. 每个自主设计必须在本清单登记，没有登记的自主设计不视为完成。
5. 状态只允许：计划中、已实现待评审、已确认、需调整。

## 记录字段

| 字段 | 说明 |
|---|---|
| ID | `ADS-xxx` |
| 开发批次 | 所属模块和功能点 |
| 功能点 | 实际实现的控件或交互 |
| 参考产品观察 | 已观察的 URL、页面、状态和截图 |
| 无法直接复用的原因 | 不存在、不可访问、不适合或与 TradeEZ 规范冲突 |
| TradeEZ 自主设计 | 使用的组件、Token、尺寸、状态和交互 |
| 偏离项 | 与参考产品的主要差异 |
| 验证结果 | 已执行的检查或测试 |
| 状态 | 计划中、已实现待评审、已确认、需调整 |

## 计划登记的 Notebook 功能点

以下项目预计需要重点关注是否产生自主设计：

- Notebook 页面三栏到移动端单栏的响应式转换
- Lexical 编辑器工具栏和统一视觉 Token 映射
- 笔记模板选择和管理弹层
- 文件夹更多操作菜单
- 笔记版本历史与内容对比
- 笔记标签创建和筛选面板
- 交易笔记与交易元数据展示
- Daily Journal 的当日统计区域
- 回收站恢复流程
- 加载、错误和只读状态

是否最终登记，以实际参考产品观察和实现结果为准。
