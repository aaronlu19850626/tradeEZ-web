# 一期需求确认补充

> 历史讨论记录，已由 [一期需求评审](一期需求评审.md) 汇总替代。用户直接选择供应商、预计模型成本、个人模板等旧表述以终审稿的最新规则为准。

状态：已确认主要范围；权重、数据供应商和安全细节待设计阶段确认。

## 已确认

- 支持多账户汇总。
- 交易计划、单笔订单复盘、日整体复盘共同参与每日综合评价。
- 建立 EZ 得分体系；Dashboard 增加百分制、多维度交易质量评估。
- 日复盘不需要版本管理。
- 系统模板允许用户修改，但系统模板不可删除；建议支持另存为个人模板。
- 交易策略需要版本管理，交易应绑定具体策略版本。
- 报告不导出文件，支持外部只读分享，并适配手机浏览。
- 资源中心的时间和事件数据通过 API 获取。
- AI 采用千问或 DeepSeek，基于本地交易数据，并可结合当日行情数据。
- AI 支持用户点击生成；部分日复盘摘要和异常提醒可自动生成并推送。
- 编辑器统一使用 Markdown 存储，富文本作为编辑界面。
- 交易记录支持周、日、全部三种视图，具体视图在交易记录模块阶段确认。
- 提供结合用户自身数据的全局 AI 对话。

## EZ 得分与交易质量评估

两者区分如下：

- EZ 得分：以交易日为单位，评价计划、执行、复盘和纪律的综合完成度。
- 交易质量评估：Dashboard 的百分制、多维度、跨周期交易质量指标，不只看盈亏。

EZ 得分候选维度：计划完成度、计划执行一致性、单笔复盘完整度、日复盘完成度、规则遵守率、风险控制、数据完整度。

交易质量评估候选维度：结果质量、执行质量、风险质量、纪律质量、复盘质量、跨日期/品种/策略/账户稳定性。

## 全局 AI 对话

- 允许用户询问自己的交易数据、策略表现、错误模式和复盘结论。
- 默认上下文由用户授权的账户、时间范围和数据权限组成。
- 可结合当日行情 API 数据，但必须展示数据时间和来源。
- 不执行下单、改止损、改账户或删除数据。
- 输出标记为分析参考，不构成投资建议。
- 支持新对话、历史对话、清空当前上下文和切换分析范围。

## AI 中心 / AI 设置

AI 需要作为一个独立的可配置、可计量、可控权限子系统，而不是仅在页面上放一个聊天按钮。

### 模型与路由

- 默认模型：由系统配置并允许用户查看；具体使用千问或 DeepSeek 待最终确定。
- 模型档位：快速、标准、深度分析，或按实际模型能力映射。
- 智能路由：简单任务使用低成本模型，复杂复盘使用高能力模型。
- 每个 AI 功能显示使用的模型和预计积分消耗。
- 管理员可配置模型、价格、单次上限、每日上限和失败重试规则。

### 积分、账单与充值

- 用户积分余额、赠送积分、购买积分和消耗积分分开展示。
- AI 调用前显示预计消耗；余额不足时阻止调用并引导充值。
- 账单明细：时间、功能、模型、输入/输出用量、积分消耗、调用状态。
- 支持充值记录、套餐、优惠/赠送积分和退款状态（支付方式后续确认）。
- 管理员可查看平台成本、用户消耗和异常调用。
- 不能在前端暴露供应商 API Key；密钥由服务端安全管理。

### 全局提示词与用户记忆

- 系统全局提示词：定义 AI 的身份、交易复盘语气、风险边界和输出格式。
- 产品模块提示词：日复盘、单笔复盘、报告、全局对话分别配置任务指令。
- 用户偏好提示词：用户可以补充自己的交易风格、关注指标和输出偏好。
- 核心记忆：交易风格、常用品种、目标、风险规则和长期偏好。
- 自动记忆开关、记忆查看、编辑、删除和重置。
- 提示词和记忆必须区分：提示词控制行为，记忆保存用户事实。

### AI 能力开关

按数据权限控制 AI 可以访问的能力：

- 交易数据与分析。
- 账户和资金数据。
- 策略与规则。
- 笔记和附件。
- 用户记忆。
- 资源中心和行情/事件数据。
- 进度、纪律和 EZ 得分。

每项能力应有说明、开关和最近使用记录。关闭能力后，AI 不得读取对应数据。

### 自动化与通知

- 用户主动生成：日复盘、报告、全局对话和专项分析。
- 系统自动生成：日终摘要、异常交易提醒、连续亏损提醒、复盘待办提醒。
- 自动生成可以配置开启/关闭、执行时间、消耗上限和通知方式。
- 自动生成结果进入通知中心，不直接覆盖用户原文。

### AI 设置页面建议结构

1. AI 总览：余额、套餐、今日消耗、本月消耗。
2. 默认模型：模型档位、智能路由、默认上下文。
3. 积分与账单：余额、充值、消费记录和账单明细。
4. 提示词与记忆：全局提示词、用户偏好、核心记忆。
5. 能力权限：各类交易数据访问开关。
6. 自动化任务：自动生成内容和通知配置。
7. 数据与隐私：数据使用范围、保留期限和重置入口。

AI 设置需要区分用户设置和管理员设置：用户不能修改平台模型成本、全局安全提示词和供应商密钥。
