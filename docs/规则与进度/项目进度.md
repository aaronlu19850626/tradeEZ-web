## 最新决策

- 用户已确认保留原 UI 框架及侧栏折叠等基础能力，固化为单一浅色工作台并移除深浅主题、样式配置入口和字体自定义；样板不视为验收通过。
- AI 用户端仅低/中/高三档能力；供应商、实际模型、档位映射和各能力模块积分价格由管理端配置。
- 已合并评分历史不重算、平台时区、日复盘跨日原稿只读且可追加、报告唯一链接、订阅与积分分离、策略版本及模板副本规则。
- 未作答的技术细节移入各模块详细设计，未视为默认同意。业务代码保持未开发状态。
- 模块开发门禁已补充：先前端 mock，用户确认后再后端接口，随后完成真实接口联调和测试；mock 不写入远程数据库。
- 模块重写规则已确认：不修改原模块源码；新模块独立重写，旧页面、组件、路由、接口和服务在新模块验收后按清单逐项删除。
- 双语规则已确认：中文/英文由全局国际化资源和语言切换统一处理，新模块不得散落硬编码单语文案；现有模块随重写逐步迁移。
- 高级数据表格基线已提升为全局规则：层次化表头与单元格、标签化状态、行内操作、危险操作居中确认；后续模块直接复用，不再重复评审该设计理念。
- 视觉基线已更新：固定单一浅色工作台、深紫侧栏、紫色操作主色；左上角显示 TradeEZ 标识，顶栏显示“TradeEZ · 记录 数据 记录 AI复盘”。
- 顶部品牌细节已更新：移除右上角样式设置入口，顶栏增高，标语改为“TradeEZ - 让复盘更简单 让进步看得见”，并接入透明背景 TradeEZ Logo。
- 全局数据视觉细节已更新：表头浅紫配色、卡片无边框阴影、标题/数值层级、顶栏状态条与中英文按钮等高对齐、侧栏 Logo/文字放大。
