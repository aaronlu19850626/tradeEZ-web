# M1 交易账户管理详细设计

版本：0.3；状态：前端 mock 已按评审修订，待用户验收；后端接口尚未进入开发。

## 1. 模块目标

账户管理只负责账户接入和维护：添加账户、生成/复制同步密钥、查看最近数据更新时间、修改账户名称、重置交易记录、物理删除账户、导入 MT5 导出的交易记录，以及进入账户交易报告入口。

页面沿用现有 Dashboard 外壳，内容区采用参考图的表格型账户工作台。添加、编辑、密钥、重置、删除、帮助和导入均在页面中间以对话框或步骤面板完成，不使用右侧抽屉。

## 2. 一期功能清单

### 2.1 账户列表

页面标题为“交易账户”。列表顶部提供“添加新账户”和“如何使用 EA”；交易导入仅在具体账户操作中提供。最多创建 10 个账户。

列表字段：

| 字段 | 规则 |
|---|---|
| 账户名称 | 必填名称；点击名称打开居中改名弹窗 |
| MT5 账号 | 上方显示券商服务器名，下方显示必填 MT5 账号；服务器可选，未填显示 N/A |
| 余额 / 净值 | 最近一条账户快照，带币种和快照时间；无数据显示 N/A |
| 最后更新时间 | 取账户快照、余额/净值或其他账户状态的最新更新时间 |
| EA 状态 | 最近 10 分钟内有心跳显示“同步中”；超过 10 分钟显示“未检测到 EA” |
| 交易记录 | 有效订单、原始成交或已导入记录数量，按现有数据口径展示 |
| 统计账户 | 已纳入默认统计范围的账户显示“统计账户”标签；支持多个 |
| 操作 | 默认统计/取消统计、交易报告、查看密钥、重置密钥、导入交易、重置交易、删除账户；顺序固定 |

列表保持宽表结构；操作直接在表格内展示，空间不足时换行，不使用三个点弹出菜单。

### 2.2 空状态

无账户时显示“还没有交易账户”和添加账户按钮，不显示导入或导出按钮。提示：创建第一个账户后自动加入统计；可将多个账户设为统计账户，用于面板和全局分析；创建后可配置 EA 或导入交易记录。已有账户但未选择统计账户时，提示点击“默认统计”，不自动选择其他账户。

### 2.3 添加账户

中间显示模态框，字段只有：

- 账户名称：必填。
- MT5 账号：客户账号号，必填。
- 券商服务器名：可选。
- 交易记录同步开始日期：必填，不能晚于平台当前日期。

提交后创建账户并生成同步密钥。创建成功的第二步居中显示连接参数、服务端地址、复制按钮和“如何在 EA 中配置”帮助链接。

账户密钥不再设计为只显示一次：账户所有者可以在账户操作中重复查看/复制当前密钥；点击“重置密钥”后生成新密钥并立即使旧密钥失效。复制操作不写入完整密钥到业务日志。

### 2.4 账户名称修改

使用居中模态框，仅编辑账户名称；保存后更新列表及统计账户名称显示。

### 2.5 交易记录重置

在居中确认模态框显示账户名称、当前记录数量、重置后的同步起点、会清理的数据范围和风险提示。用户输入准确的账户名称确认后执行。

一期沿用现有“清空交易数据并重新同步”语义：清理账户交易记录、派生交易、同步轮次和批次；账户本身、账户名称和当前密钥保留，交易记录重置不重置密钥。

### 2.6 物理删除

用户明确要求物理删除。居中危险确认模态框必须显示影响范围，要求输入准确的账户名称后执行。

物理删除将删除该账户及其关联交易、快照、同步记录、复盘关联和附件。删除不可通过页面撤销；审计日志只保留必要的操作记录，不保留已删除业务数据副本。已有报告或历史页面引用该账户时，删除后的处理方式在报告模块设计中统一确认。

### 2.7 账户交易报告入口

每个账户提供“交易报告”操作，进入 `/dashboard/analytics?account_id=<id>` 或后续确定的报告路径。当前只完成入口、账户参数传递和空状态提示，报告计算逻辑放到交易报告模块开发阶段。

### 2.8 统计账户

每个账户独立设置是否参与默认统计，允许同时选择多个，也允许全部取消。未选中时操作为“默认统计”，选中后显示“统计账户”标签及“取消统计”操作。切换只影响当前账户，不能清除其他账户的选择。首个创建的账户自动加入统计，后续新账户默认不加入。删除账户只移除该账户，不自动把其他账户加入统计。重置交易和重置密钥保留统计选择。

统计账户集合将作为面板和全局分析的初始范围，汇总为简单合并。未选统计账户时显示引导提示，不默认为全部账户。当前阶段仅实现账户管理前端 mock 交互；全局范围联动和持久化在对应模块确认后实现。

### 2.9 EA 帮助

页面和添加账户成功页都提供“如何使用数据同步 EA”链接。帮助内容包括 EA 安装和加载、服务端地址、密钥粘贴位置、MT5 WebRequest 白名单、心跳判断，以及认证失败、地址不可达和时间偏差处理。

### 2.10 导入 MT5 交易记录

账户页提供“导入交易记录”入口，交互采用居中步骤模态框：选择目标账户或创建后再导入；上传 MT5 导出文件；预览行数、时间范围、品种、方向、订单号及预计新增/重复/异常数量；确认导入并显示进度和结果。

一期只支持 MT5 标准 CSV 导出；HTML 或其他格式作为后续兼容项。导入必须保留原始文件摘要、导入批次和错误行结果，不覆盖 EA 已同步的事实数据。重复判断沿用账户、ticket、position_id 等已有唯一性规则，重复记录标记为重复，不重复插入。

## 3. 数据结构调整

继续使用现有 `accounts`、同步 Key、`deals`、`trade_lifecycles`、`snapshots`、`heartbeats`、`sync_runs`、`sync_batches` 和维护审计结构。账户快照继续从 `snapshots` 读取 balance、equity、margin、free_margin、margin_level 和时间。

必要调整：

| 调整 | 说明 |
|---|---|
| 新模块 `is_statistics` | 每账户独立布尔值，无单用户唯一约束；前端 mock 字段为 `isStatistics` |
| 导入批次表 | 保存 user、account、文件摘要、文件名、导入时间、行数、成功/重复/异常数量和状态 |
| 导入错误表或错误 JSON | 保存行号、错误原因和脱敏的原始行摘要 |
| 账户更新时间口径 | `last_updated_at = max(snapshot_time, last_seen_at, last_success_sync_at, updated_at)` |
| EA 状态口径 | 最近心跳 10 分钟内为正常，否则未检测到 |

密钥继续使用当前加密存储和哈希校验；重复复制接口只向已认证的账户所有者返回当前完整密钥，不写入日志。

## 4. 页面交互和状态

- 加载：保留页面标题和表头骨架，避免空白跳动。
- 空账户：显示空状态创建区。
- 接口错误：保留已有列表，显示局部错误和重试，不把账户数量重置为 0。
- 快照缺失：余额/净值显示 N/A；最后更新时间显示其他有效更新时间或“暂无”。
- EA 超过 10 分钟无心跳：显示“未检测到 EA”，并提供帮助链接。
- 所有添加、编辑、密钥、重置、删除和导入流程使用居中模态框；桌面宽度 520–680px，导入预览可到 760px；手机端使用接近全屏的居中模态页面。
- 处理中禁止重复提交；成功后关闭模态框并刷新对应账户行。

## 5. API 方案

- `GET /api/v1/accounts`：返回账户名称、账号、服务器、统计标识、最新快照、最后更新时间、最近心跳、EA 状态和统计数量。
- `POST /api/v1/accounts`：接受名称、账号、同步开始日期和服务器（可选），创建账户。
- `PATCH /api/v1/accounts/{id}`：支持名称和统计账户等轻量设置。
- `POST /api/v1/accounts/{id}/regenerate-key`：重置密钥并返回新密钥。
- `GET /api/v1/accounts/{id}/sync-key`：认证后重复获取当前密钥；记录访问审计但不记录密钥内容。
- `POST /api/v1/accounts/{id}/reset-sync`：清空交易记录并重置同步起点。
- `DELETE /api/v1/accounts/{id}`：物理删除并返回删除影响摘要。
- `POST /api/v1/accounts/{id}/imports` 与 `GET /api/v1/accounts/{id}/imports/{batch_id}`：创建并查询 MT5 文件导入批次。
- `GET /api/v1/accounts/{id}/report`：一期只保留入口契约，报告逻辑在报告模块实现。

## 6. 验收标准

- 无账户首次进入显示完整空状态，可直接添加账户，创建后在该账户内导入文件。
- 添加账户要求名称、MT5 账号和同步开始日期；券商服务器可为空。
- 密钥可重复复制；重置后旧密钥立即不可用。
- 列表显示余额、净值、快照时间、最后更新时间和 EA 状态。
- EA 心跳 10 分钟内显示同步中，超过 10 分钟显示未检测到 EA。
- 可修改账户名称、设置或取消多个统计账户、物理删除账户、重置交易记录。
- 多个账户可同时显示统计标签；全部取消时出现引导；删除统计账户不会自动选中其他账户。全局联动列为后续验收项。
- 帮助链接在列表页和添加账户成功页可达。
- 可导入 MT5 CSV，导入前可预览，重复和错误行有明确结果。
- 所有流程使用居中交互，不使用右侧抽屉。
- 交易报告入口可带账户上下文进入后续页面，当前不要求报告计算完成。

## 7. 已确认的三个实现细节

1. MT5 账号必填，账户必须能够被 EA 同步协议识别。
2. MT5 导入首期只支持 CSV，HTML/XLSX 放到后续版本。
3. 交易记录重置不重置同步密钥；密钥重置作为独立操作。

本稿已完成边界确认，下一步只进入账户模块前端 mock 原型；前端交互确认后再开发数据库迁移和后端 API。
