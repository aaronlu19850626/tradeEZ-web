# AI 中心模块设计 v0.1

状态：历史需求稿，待核心模块盘点后重新评审；旧一期需求来源已经归档，不能据此直接进入前端 Mock 或后端开发。

## 1. 定位与边界

AI 是**复盘助手**，不是交易执行者：

- 只能读取用户授权范围内的数据，做生成、改写、摘要、补全、结构化与问答。
- 不执行下单、不改止损、不改账户、不删除数据；不承诺收益。
- 所有输出标注"分析参考，不构成投资建议"；引用行情/事件数据必须显示数据时间与来源。
- 没有可靠数据时明确说明"数据不足"，不编造行情、事件或指标。
- 用户可查看、编辑、拒绝、撤销、删除任何 AI 生成内容；AI 结果不直接覆盖用户原文。

## 2. 一期范围（建议）

| 项 | 一期 | 说明 |
|---|---|---|
| 全局 AI 对话 | ✅ | 基于本人授权账户/时间范围/数据权限问答，支持新对话、历史、清空上下文、切换范围 |
| 日复盘摘要 | ✅ | 用户点击生成：当日 P&L、计划与执行对照、最好/最差交易、典型错误、情绪、明日改进 |
| 单笔交易 AI 整理 | ✅ | 把散乱笔记整理为结构化复盘结论（对接即将开发的复盘模块） |
| AI 设置页（7 段） | ✅ | 余额与套餐、默认模型、积分与账单、提示词与记忆、能力权限、自动化、数据与隐私 |
| 积分计量与账单 | ✅ | 调用前预估、扣费、余额不足阻断、账单明细；充值入口先占位 |
| 能力开关（数据权限） | ✅ | 关闭的能力 AI 不得读取，且要在调用日志留痕 |
| 智能路由（三档） | ✅ | 快速/标准/深度，按任务复杂度与用户档位选择 |
| 自动生成与推送 | ⏳ 二期 | 日终摘要、异常交易提醒、连续亏损提醒、复盘待办；一期先留配置项与任务表结构 |
| 行情/事件数据接入 | ⏳ 待定 | 需要确认供应商（资源中心的 API）；一期先不做，接口位预留 |

## 3. 架构

```
前端（AI 设置页 / 全局对话抽屉 / 各模块 AI 按钮）
   │  SSE 流式
   ▼
AI 网关（新模块 backend/app/ai_center/）
   ├── 鉴权与权限：账户范围、时间范围、能力开关（关闭即不进入上下文）
   ├── 上下文构建：把交易/统计/策略/笔记整理成结构化摘要（不直传大表）
   ├── 提示词装配：系统全局提示词 + 模块提示词 + 用户偏好提示词 + 核心记忆
   ├── 档位与路由：快速/标准/深度 → 供应商 + 模型（管理端配置）
   ├── 计量与扣费：预估 → 调用 → 用量结算 → 写积分流水与账单
   ├── 安全：密钥仅服务端、输出过滤、免责声明、提示注入防护
   └── 审计：调用日志（功能、模型、token、积分、状态、耗时、错误）
   ▼
供应商适配层（OpenAI 兼容协议）
   ├── 千问（DashScope OpenAI 兼容端点）—— 建议默认
   └── DeepSeek —— 备选/降级
```

## 4. 数据模型（新增表）

| 表 | 作用 | 关键字段 |
|---|---|---|
| `ai_providers` | 供应商与密钥（服务端加密存储，管理端维护） | `code`(qwen/deepseek)、`base_url`、`api_key_encrypted`、`enabled` |
| `ai_models` | 档位 → 供应商模型映射 | `tier`(fast/standard/deep)、`provider_code`、`model_name`、`enabled` |
| `ai_feature_prices` | 功能 × 档位积分价格与限额 | `feature`、`tier`、`credits`、`max_per_call`、`max_per_day` |
| `ai_credit_ledger` | 积分流水（赠送/购买/消耗/退款） | `user_id`、`change`、`balance_after`、`source`、`ref_id` |
| `ai_usage_logs` | 每次调用账单与审计 | `user_id`、`feature`、`tier`、`model`、`input_tokens`、`output_tokens`、`credits`、`status`、`duration_ms`、`error_code` |
| `ai_conversations` / `ai_messages` | 全局对话会话与消息 | `user_id`、`title`、`scope_json`(账户/时间/权限快照) |
| `ai_prompts` | 系统全局 / 模块 / 用户偏好提示词 | `scope`(system/module/user)、`module`、`user_id`、`content` |
| `ai_memories` | 核心记忆条目 | `user_id`、`kind`、`content`、`auto`（是否自动记忆） |
| `ai_capability_settings` | 用户能力开关 | `user_id`、`capability`、`enabled`、`last_used_at` |
| `ai_automation_tasks` | 自动生成任务（二期执行，一期先存配置） | `user_id`、`kind`、`enabled`、`schedule`、`credit_cap`、`notify` |

## 6. 前端结构

1. **AI 设置页**（`/dashboard/ai-settings`）按 7 段组织：AI 总览 / 默认模型 / 积分与账单 / 提示词与记忆 / 能力权限 / 自动化任务 / 数据与隐私。用户设置与管理员设置严格分离，用户看不到平台成本与密钥。
2. **全局 AI 对话**：右侧抽屉，可从任意页面唤起；顶部显示当前上下文（账户范围、时间范围、已授权能力），支持新对话/历史/清空上下文/切换范围；消息流式输出，带"分析参考，不构成投资建议"标记与引用来源。
3. **模块内 AI 入口**：日复盘卡片"AI 生成摘要"、单笔复盘"AI 整理笔记"、报告页"AI 摘要与建议"；生成前显示预计积分，余额不足时阻断并引导充值。
4. **AI 能力提示**：能力开关关闭时，相关入口置灰并提示"未授权 AI 访问该数据"。

## 7. 计量、积分与成本

- 调用前：显示功能、档位、预计积分；余额不足直接阻断。
- 调用后：按供应商返回的 token 用量结算积分，写 `ai_credit_ledger` 与 `ai_usage_logs`；失败调用按规则回滚或计入失败记录（不计费）。
- 智能路由：短问答→快速档；日复盘摘要→标准档；跨周期深度分析→深度档；用户可手动指定档位。
- 限额：单次上限、每日上限（管理端可配），超出时提示而非静默失败。
- 密钥：只在服务端保存与解密，任何接口不回传密钥明文。

## 8. 安全与合规

- 输出统一带免责声明；行情/事件数据必须带时间与来源，缺失时明确说明。
- 上下文只包含用户已授权能力范围内的数据；关闭能力后不进入提示词，并在日志中留痕。
- 提示注入防护：外部文本（笔记、备注、行情摘要）作为数据而非指令；系统提示词优先级最高。
- 数据保留：会话与日志保留期可配置，提供"清空上下文"与"删除全部 AI 数据"入口。
- 审计：每次调用可追溯到用户、功能、模型、授权范围与消耗。

## 9. 分期与验收

**一期**

1. AI 设置页 7 段可用（余额、档位、账单、提示词与记忆、能力开关、自动化配置、隐私）。
2. 全局对话可用（流式、上下文范围可见、历史可查、可清空）。
3. 日复盘摘要与单笔笔记整理可用（点击生成、可编辑、可拒绝、不覆盖原文）。
4. 积分计量与账单正确：预估 → 扣费 → 明细可核对；余额不足阻断。
5. 能力开关生效：关闭能力后 AI 不读取对应数据。
6. 免责声明与来源标注齐备。

**二期**：自动生成与推送、平台成本看板、更多模块 AI 能力、行情/事件数据接入。
