# 多币种与国内期货准备方案

版本：0.1；状态：方案已确认，待进入账户币种与筛选实现。

## 1. 目标与范围

- 账户设置增加必填且不可修改的币种。
- 币种字典：`USD、CNY、EUR、GBP、JPY、HKD`。
- 预埋平台默认币种映射：`mt5 -> USD`、`ctp -> CNY`。
- 账户同时预埋市场属性：`ctp -> cn`、其他平台默认 `fx`，用于国内红涨绿跌和外汇绿涨红跌。
- 交易记录、交易总览增加币种筛选，并沿用现有品种筛选。
- 混合币种账户同时选中时，强制选择单一币种后才能进行汇总。
- 为国内期货预留账户、订单、成交、品种、资金快照的数据结构扩展；多平台连接器架构见《多平台交易数据同步架构》。
- 一期不实现汇率换算；所有金额按交易原币展示和计算。

## 2. 已确认决策

1. 币种清单一期包含 `USD、CNY、EUR、GBP、JPY、HKD`。
2. 混合币种账户同时选中时，一期强制选择单一币种。
3. 账户币种创建后不允许修改。
4. 国内期货平台预埋平台代码 `ctp`，默认币种 `CNY`。
5. 交易品种筛选继续沿用现有品种字段，未来按平台扩展交易所、产品代码和合约代码。
6. 金额格式化从硬编码美元改为统一币种感知工具。

## 3. 统一处理逻辑

账户币种沿用 `accounts.account_currency`，但提升为“用户配置、账户级、不可修改”的权威字段。EA 心跳不再覆盖已配置币种，只有币种为空的历史账户才允许由心跳补填。

交易记录的 `currency` 从账户继承。所有金额指标以交易原币计算。当前账户范围存在多种币种时，总览和交易统计不进行混合合计；用户选择单一币种后，只统计该币种的账户和交易。

品种选项从前端全量交易改为从当前账户范围和币种范围派生。这样筛选选项与统计范围保持一致，也避免跨平台品种混在一起。

## 4. 账户数据方案

`accounts` 表先做兼容性扩展，不破坏现有 MT5 同步：

- 新增 `external_login TEXT`，作为平台无关账号标识。
- 新增 `broker_code TEXT`，用于 CTP 期货公司或前置环境。
- 保留 `mt5_login`，继续服务旧同步协议。
- 回填 `account_currency` 并设为 `NOT NULL`。
- MT5 账户回填 `external_login = mt5_login`、币种 `USD`。
- CTP 账户默认 `external_login = 投资者账号`、币种 `CNY`、`broker_code = 期货公司/前置代码`。
- 唯一性最终调整为 `platform + broker_code + external_login`，迁移阶段先保留旧约束。

账户创建接口升级为通用字段：

```json
{
  "name": "string",
  "platform": "mt5 | ctp",
  "currency": "USD | CNY | EUR | GBP | JPY | HKD",
  "login": "string",
  "broker_code": "string | null",
  "broker_server": "string | null",
  "sync_start_date": "date"
}
```

`login` 同时兼容 MT5 数字账号和 CTP 投资者账号。更新接口只允许修改名称和统计账户，不允许修改币种。平台为 `ctp` 时，币种自动默认并锁定为 `CNY`。

## 5. 国内期货交易数据方案

当前 `deals` 是 MT5 成交事件，不能承载 CTP、cTrader、ATAS 等其他平台。非 MT5 平台准备采用独立原始表或通用原始事件表：

- `ctp_orders`：本地报单引用、交易所报单编号、FrontID、SessionID、方向、开平标志、投保标志。
- `ctp_trades`：成交编号、成交时间、价格、手数、费用、平仓/持仓盈亏。
- `ctp_positions`：持仓明细、今昨仓、保证金、结算相关字段。

最终统一构建到 `trade_lifecycles`。交易中心和总览不再直接读取 `deals`，改为读取统一交易视图，由 MT5、MT4、cTrader、ATAS、CTP 等平台连接器各自生成同一套闭环交易结构。

`symbols` 表增加 CTP 字段：`exchange_id、product_id、contract_id、contract_multiplier、price_tick、delivery_month`。MT5 继续使用现有字段，品种筛选统一展示规范化名称。

资金快照预留 CTP 字段：可用资金、动态权益、占用保证金、冻结保证金、持仓盈亏、平仓盈亏、结算相关字段。原始 CTP 数据保留 `raw_json`，统一快照服务按平台解析。

## 6. 接口与筛选方案

交易接口统一增加币种参数：

- `GET /api/v1/trades?currency=USD&symbol=...`
- `GET /api/v1/trades/currencies` 返回当前可筛币种。
- `GET /api/v1/trades/symbols` 返回品种，并支持按账户范围收窄。

`TradeFilter` 在现有 `side/result/symbol` 基础上增加 `currency`。筛选参数进入查询契约和 URL 深链。

前端共享筛选结构：

```ts
{
  accountIds,
  range,
  side,
  result,
  currency,
  symbol
}
```

账户中心创建表单增加币种选择，编辑界面只读显示币种。金额格式化抽成统一工具，替换当前硬编码 `$`。

## 7. 开发计划

1. 冻结本方案并补充测试清单。
2. 后端账户层：迁移、回填、币种校验、心跳覆盖策略、账户创建与更新契约。
3. 前端账户层：币种选择、平台默认映射、列表和只读展示。
4. 后端交易层：统一交易视图、币种筛选、币种选项接口。
5. 前端交易层：交易记录和总览币种筛选、混合币种强制选择、URL 深链、统一金额格式化。
6. 多平台连接器与数据准备：账户标识扩展、原始订单/成交/持仓表设计、品种扩展，覆盖 MT4、cTrader、ATAS、CTP 等平台，暂不接全部真实行情。
7. 回归测试、迁移验证、文档更新和用户验收。

## 8. 验收重点

- 每个支持币种都能创建账户，币种创建后不可修改。
- MT5 默认 USD，CTP 默认并锁定 CNY。
- 交易记录和总览筛选币种与品种均生效，刷新和深链可恢复。
- 同时选中 USD 与 CNY 账户时，汇总前强制选择单一币种，不出现混合金额合计。
- CNY 账户金额正确显示人民币符号和小数位，不再显示 `$`。
- 旧账户迁移后币种为 USD，历史统计和交易记录保持可用。
- CTP 平台和币种映射已预埋，后续可直接接入订单、成交、持仓和资金快照。

## 9. 风险与边界

- `account_currency` 当前由心跳管理，迁移时需先回填再改写入策略。
- 现有多个金额格式化函数硬编码美元，统一后需要全量回归账户、交易记录、总览。
- 多币种会改变汇总语义，必须在 UI 和 API 两层同时阻止混合币种合计。
- `mt5_login` 全局唯一约束需要逐步放宽，不能直接删除。
- 国内期货的资金、结算、手续费、平今平昨规则不能照搬外汇口径，需在 CTP 接入阶段单独建模。
