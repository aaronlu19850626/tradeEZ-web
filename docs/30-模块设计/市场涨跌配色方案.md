# 市场涨跌配色方案

版本：1.0；状态：已确认并完成第一版实现。

## 1. 目标

- 国内股票、国内期货使用“红涨绿跌”。
- 外汇及海外默认品种使用“绿涨红跌”。
- 交易结果颜色跟随市场，不改变按钮、同步状态、错误和警告等产品语义色。
- Light / Dark 两套主题使用同一套市场规则。

## 2. 市场属性

账户新增权威字段 `market_profile`：

| 值 | 含义 | 当前默认映射 |
|---|---|---|
| `cn` | 国内股票与期货 | `ctp -> cn` |
| `fx` | 外汇及海外默认品种 | 其他平台 -> `fx` |

数据库迁移为 `0039_account_market_profile`。账户接口返回 `marketProfile`，交易记录接口返回每条交易的 `marketProfile`。

## 3. 配色语义

交易盈亏和行情涨跌只使用 `profit / loss` Token：

| 市场 | 正收益 / 上涨 | 负收益 / 下跌 |
|---|---|---|
| `cn` | 红色 | 绿色 |
| `fx` | 绿色 | 红色 |

以下语义色固定，不随市场切换：

- `success`：同步成功、完成、正常状态，始终为绿色。
- `danger / destructive`：系统错误、删除、危险操作，始终为红色。
- `warning`：警告和待处理，始终为琥珀色。
- `info`：信息和中性提示，始终为蓝色。
- `primary`：品牌和主操作，不使用红绿表达涨跌。

## 4. 前端实现

- 全局颜色入口：`frontend/src/app/globals.css`。
- 市场解析：`frontend/src/lib/market-colors.ts`。
- 作用域：`frontend/src/components/shared/market-color-provider.tsx`。
- `MarketColorProvider` 同时在页面容器和 `document.documentElement` 设置 `data-market-profile`，确保 Dialog Portal 和 Canvas 图表也能取得正确颜色。
- Recharts、SVG 优先读取 `var(--profit-*)` 和 `var(--loss-*)`。
- Lightweight Charts 等需要具体色值的组件通过 `readMarketColor` 读取当前主题颜色。

## 5. 混合市场

当前账户范围同时存在 `cn` 与 `fx` 时：

1. 筛选器强制选择一个市场，提供“国内市场 / 外汇市场”选项。
2. `market_profile` 进入列表、汇总、分组、总览、日历和 URL 深链。
3. CNY 默认联动 `cn`，USD 默认联动 `fx`。
4. 任意聚合视图只使用当前单一市场配色，不混合两种红绿规则。

## 6. 影响范围

- 交易总览：指标卡、日历、每日净损益、累计净损益、回撤和最近交易。
- 交易记录：统计卡、日/周分组、全部记录、日视图、周视图和日明细弹窗。
- 行情图：K 线、上涨/下跌区域和累计曲线。
- 设计系统：展示国内与外汇两套配色，并标明固定语义色。

## 7. 验收标准

- CTP / CNY 账户盈利显示红色，亏损显示绿色。
- MT5 外汇账户盈利显示绿色，亏损显示红色。
- 切换市场后图表、日历、表格和金额颜色一致更新。
- `success / danger / warning / info` 不因市场切换而反转。
- Light / Dark 下颜色对比度正常，且仍保留正负号和方向文字。
