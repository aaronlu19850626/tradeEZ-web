# 单笔交易复盘首版

入口：完整订单 → 点击交易编号 → 交易复盘。侧栏“交易复盘”汇总已保存记录。

支持草稿/已复盘、最长 20000 字笔记、最多 20 个不重复标签（每个 40 字）、分页汇总、保存冲突提示及未保存退出提醒。标签当前为单笔交易的自由标签，支持标签批量重命名与合并，尚无独立标签分类。

标签汇总已实现：`GET /api/v1/my/review-tags` 支持当前用户账户范围、名称子串搜索及分页，按使用复盘数降序排列；同一复盘中重复标签只计一次，包含草稿及待恢复笔记。复盘汇总页点击标签应用精确筛选，交易详情中可选已有标签加入当前输入，保存复盘后才落库。已提供批量重命名和合并，尚未提供独立删除标签。65 项后端测试通过，含标签计数、去重、账户隔离、搜索和分页覆盖。

人工资料以 account_id + position_id + anchor_ticket 独立保存，不依赖派生 Trade ID 外键。重复同步不覆盖笔记；资料使用版本号阻止两个窗口相互覆盖。保存时校验成交与分摊摘要，成交变更后提示重新核对。

重同步保留复盘资料。没有匹配交易的资料在汇总中显示“待恢复／范围外”，可阅读全文；重新同步得到相同持仓和 anchor 时恢复关联。生命周期边界改变时，不推断关联到新 anchor，保留为待恢复资料。人工重新关联和范围外分类尚未实现。账户删除会通过外键清除其复盘，影响预览包含复盘数量。

汇总页支持按账户、草稿／已复盘、已关联／待恢复关联、精确标签及笔记／品种／持仓编号关键词组合筛选。点击查询应用条件并返回第一页；清空筛选恢复全部记录。服务端使用同一条件计算总数与分页结果，所有查询限定当前用户。关键词按字面子串匹配，百分号、下划线不作为通配符；英文关键词不区分大小写。标签精确匹配并忽略输入首尾空格。

当前未实现：Setup/Playbook、执行评分、情绪/错误业绩分组、人工关联恢复及历史版本恢复。结构化情绪/错误分类、结论和下次行动、草稿自动保存及只读历史版本已实现，见 [结构化复盘](../20-产品与需求/评审复盘.md)。未填写复盘的交易可从完整订单进入，汇总页只列已有复盘；“草稿”不包含从未保存笔记的交易。

迁移 0004_trade_reviews 已应用。迁移前备份：backups/before-trade-reviews-20260918.sqlite。64 项后端测试通过，包含跨用户隔离、旧版本保存拒绝、源数据修正、重复同步、重同步保留恢复及删除级联。浏览器验证汇总空状态和真实交易的复盘表单，未向真实交易写入测试笔记。未运行前端 build/lint（遵循项目要求）。

筛选功能追加验证：65 项后端测试全部通过，新增组合筛选、分页总数、跨账户范围、非法参数、字面关键词、标签精确匹配与孤立笔记筛选用例。局域网浏览器已验证查询无结果、清空筛选及账户选项加载；未修改真实交易或笔记。本机与局域网 API 均已重启并确认健康。

## 批量标签维护

交易复盘 → 复盘标签 → 重命名／合并标签。作用范围采用已应用的账户筛选（当前账户或我的全部账户），不采用状态、关键词等其他筛选。原标签精确匹配，新名称已有记录时合并并去重；包含草稿和待恢复资料。预览展示涉及账户、复盘数量和重复数量，无匹配时禁止提交。

接口 POST /api/v1/my/review-tags/change-preview 与 POST /api/v1/my/review-tags/change。预览摘要绑定用户、账户范围、新旧名称及相关复盘版本；提交在写事务内再次比对。相关数据改变返回 409，要求重新预览；更新复盘版本以阻止其他窗口旧内容覆盖。笔记、状态和成交核对摘要保持不变；中途失败整批回滚。暂无一键撤销，合并前会明确提示。

66 项后端测试通过，新增账户隔离、合并去重、并发修改、重复提交及事务回滚覆盖。真实账户未用于标签修改测试。

## 复盘截图

保存复盘后可上传静态 PNG、JPEG、WebP，原文件及转换后的 PNG 均限制 5 MB，最多 1600 万像素；每份复盘最多 10 张，每账户总容量 100 MB。图片解码后重新编码为 PNG，不保留图片元数据、原始文件名或尾部附加内容，相同像素编码结果去重。依赖 Pillow==12.3.0。

列表、原图、上传、删除都校验当前用户的账户归属。原图不使用公开地址，通过 Bearer 鉴权后在浏览器创建临时 Blob URL；下载为 PNG。选择文件后需点击上传，上传和删除独立于笔记保存，立即生效。删除有确认且不提供撤销。

截图 BLOB 存在 SQLite 的 review_attachments 表，通过 review_id 关联人工复盘。重同步保留并可在待恢复笔记中查看；删除账户时级联清理。维护预览包含截图数量及摘要，附件变化会使旧预览失效。备份数据库即包含附件；删除后数据库文件不保证立即缩小。当前附件接口不经过 JSON 请求体审计缓冲，避免把图片读取成日志，尚无独立附件操作审计。

迁移 0005_review_attachments；迁移前备份 backend/backups/before-review-attachments-20260918-182600.sqlite。71 项后端测试通过，含三种图片格式、动图拒绝、元数据清理、像素限制、非法图片、大小限制、重复上传、权限隔离、数量上限、重同步保留、维护预览失效及删除级联。真实账户未上传测试图片。

局域网浏览器已确认交易详情中的“先保存一次复盘，即可上传截图”入口提示；上传／删除链路使用临时数据库测试，未向真实交易写入测试笔记或截图。本机和局域网 API 均健康，已应用 0005 迁移。

## 从订单查找待复盘交易

完整订单列表新增独立的复盘状态列与筛选：未填写（无已保存复盘）、草稿、已复盘，可与账户、品种和交易状态组合。交易数据的“待核对”与人工复盘状态独立。已保存复盘对应的成交发生修正时，列表提示“成交已变化，请复核笔记”，保留原状态。

GET /api/v1/my/orders 新增 review_status 参数（unwritten/draft/reviewed），返回 review_status 与 review_source_changed；详情同样返回这两个字段。按账户、持仓号、开仓成交锚点关联，列表总数与分页使用同一读事务，变更提示在该事务内计算。保存复盘与关闭详情后刷新列表，筛选后末页消失时自动退回有效页。

72 项后端测试通过，新增三种复盘状态、组合筛选、分页总数、跨账户访问与源成交修正验证。
