# 账户模块旧模块下线清单

版本：1.0；状态：待执行。触发条件：新账户模块 `/dashboard/account-center` 通过用户验收。

本清单记录旧账户模块的下线范围、替代关系、影响和回滚点。未验收前不删除，只保留隔离状态。

## 1. 前端旧模块

| 范围 | 路径 | 说明 |
|---|---|---|
| 旧页面 | `frontend/src/app/(main)/dashboard/accounts/**` | 已被 `/dashboard/account-center` 替代 |
| 旧账户客户端类型/方法 | `frontend/src/lib/tradesync/api.ts` 中 `Account`、`AccountWithKey`、`AccountStatus` 及 `api.accounts/createAccount/updateAccount/maintenancePreview/maintenanceAudits/regenerateKey/resetSync/deleteAccount` | 新模块使用 `account-center.ts` |

导航已调整：`sidebar-items.ts` 的“账号与 EA”和 `today/page.tsx` 的入口均已指向 `/dashboard/account-center`。

## 2. 后端旧模块

| 范围 | 路径 | 说明 |
|---|---|---|
| 旧账户路由 | `backend/app/accounts/router.py` | 已在 `main.py` 停止挂载，可删除 |
| 旧账户维护 | `backend/app/accounts/maintenance.py` | 旧 reset/delete 逻辑，可删除 |
| 旧账户仓储 | `backend/app/accounts/repository.py` | 旧账户 SQL，可删除 |
| 旧账户响应组装 | `backend/app/accounts/service.py` | `create_account/list_accounts/update_account/regenerate_account_key/account_to_out` 可删除；但 `hash_sync_secret` 仍被 `main.py` 的 legacy `authenticate_ingest` 使用，需先迁到 `app/common` 或 `app/crypto` |
| 账户同步策略 | `backend/app/accounts/policies.py` 的 `ensure_account_active` | 被 `sync/auth.py`、`sync/router.py` 依赖，属于共享策略，需迁到 `app/common` 或 `app/sync`，不能直接删除 |

## 3. 旧 schemas

`backend/app/schemas.py` 中 `AccountCreateIn`、`AccountUpdateIn`、`AccountOut`、`AccountKeyOut`、`AccountMaintenanceIn`、`AccountResetIn` 为旧账户契约。`DealIn`、`DealBatchIn`、`HeartbeatIn` 等 legacy ingest 模型仍被 `main.py` 的 legacy 接口使用，需与 legacy 接口一起下线，不在账户模块单独删除。

## 4. 旧测试

- `tests/test_account_notes.py`：已删除。
- `tests/test_sync_handshake.py` 中 `test_account_configuration_and_initial_cursor`、`test_account_reset_and_delete_fence_old_requests`：已 `skip`，验收后删除。
- `tests/test_sync_handshake.py` 中 `test_account_reset_failure_rolls_back_facts_and_key`：仍直接调用旧 `app.accounts.maintenance.execute`，下线时随旧模块删除。

## 5. 影响与回滚

- 影响：直接访问 `/dashboard/accounts` 会停留在旧页面，且其调用 `/my/account-maintenance-audits`、`/maintenance-preview` 等接口已返回 404；导航入口已切换，不再引导用户进入。
- 替代：所有账户管理能力均由 `/dashboard/account-center` 与 `backend/app/account_center` 提供。
- 回滚点：保留 `git` 版本历史；`app/accounts`、旧页面和 `api.ts` 旧方法在验收前不删除。
