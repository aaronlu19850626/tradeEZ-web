# 账户模块后台契约与迁移方案

版本：1.0；状态：已确认，待实现。代码入口：`backend/app/account_center/`。

本文是交易账户模块独立后台实现的冻结契约。前端 mock 已确认，本稿覆盖后端接口、数据口径、迁移和测试范围；CSV 导入为同里程碑第二个小批次并已实现。

## 1. 路由与旧模块策略

新建 `backend/app/account_center/`，在 `main.py` 用它接管 `/api/v1/accounts/*`。旧 `backend/app/accounts/*` 源码原样保留、不再挂载，等新模块验收后再按清单删除。

## 2. 字段契约

对外统一 snake_case，日期为 `YYYY-MM-DD` 字符串，服务端转 UTC Unix 秒存储。

| 对外字段 | 类型 | 说明 | 数据库映射 |
|---|---|---|---|
| `id` | int | 账户 ID | `accounts.id` |
| `name` | string | 账户名称，必填 | `accounts.label` |
| `mt5_login` | int | MT5 账号，必填，全局唯一 | `accounts.mt5_login` |
| `broker_server` | string|null | 券商服务器，可选 | `accounts.broker_server` |
| `sync_start_date` | string | 同步开始日期 `YYYY-MM-DD`，不能晚于平台当天 | `accounts.sync_start_time` |
| `is_statistics` | bool | 是否统计账户 | `accounts.is_statistics`（新增列） |
| `currency` | string|null | 账户币种 | `accounts.account_currency` |
| `status` | string | 账户状态 | `accounts.status` |
| `balance` / `equity` | float|null | 最近快照余额/净值，缺失 N/A | `snapshots` |
| `snapshot_time` | int|null | 最近快照 UTC 秒 | `snapshots.timestamp` |
| `last_updated_at` | int|null | `max(snapshot_time, last_seen_at, last_success_sync_at)` 的 UTC 秒；账户配置变更不计入，从未同步保持为空 | 派生 |
| `heartbeat_at` | int|null | 最近心跳 UTC 秒 | `heartbeats.last_seen_at` |
| `ea_status` | string | `online` / `offline`；心跳距今 ≤600s 为 online | 派生 |
| `trade_count` | int | 已同步的不同 `position_id` 数量 | `deals` |
| `key_prefix` / `key_environment` / `key_created_at` | - | 密钥元信息，不回传明文 | `accounts` |
| `created_at` | string | 创建时间 | `accounts.created_at` |

## 3. 接口契约

鉴权：Bearer 用户 JWT。

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| GET | `/api/v1/accounts` | - | `list[AccountOut]` |
| POST | `/api/v1/accounts` | `{name, mt5_login, broker_server?, sync_start_date}` | 201 `AccountKeyOut` |
| GET | `/api/v1/accounts/{id}` | - | `AccountOut` |
| PATCH | `/api/v1/accounts/{id}` | `{name?, is_statistics?}` | `AccountOut` |
| GET | `/api/v1/accounts/{id}/sync-key` | - | `{sync_key}` |
| POST | `/api/v1/accounts/{id}/regenerate-key` | - | `AccountKeyOut` |
| POST | `/api/v1/accounts/{id}/reset-sync` | `{name, sync_start_date}` | `AccountOut` |
| DELETE | `/api/v1/accounts/{id}` | `{name}` | `{message}` |
| GET | `/api/v1/accounts/{id}/report` | - | `{account, report: null, message}` |
| POST | `/api/v1/accounts/{id}/imports` | `multipart/form-data` 上传 MT5 CSV | 导入结果 `{batch_id, imported_rows, duplicate_rows, error_rows, errors[]}` |
| GET | `/api/v1/accounts/{id}/imports/{batch_id}` | - | 批次详情与错误行 |

## 4. 业务规则

- 每用户最多 10 个账户，创建并发安全（advisory lock + 计数校验）；新建账户默认 `is_statistics=true`，用户可随后单独取消。
- 密钥可重复查看；`regenerate-key` 使旧密钥立即失效，交易保留。
- `reset-sync` 只清交易、派生交易、复盘/核对和同步轮次批次，重置 `sync_start_time`、游标归零；**不轮换密钥**，保留统计选择。
- `delete` 物理删除账户及其关联数据；确认方式为精确输入账户名称。
- 密钥存储、鉴权和日志不泄漏明文密钥。

## 5. 迁移

`0024_account_center`：`accounts` 新增 `is_statistics BIGINT NOT NULL DEFAULT 0`。

`0025_account_imports`：新增 `account_import_batches` 与 `account_import_errors`。
