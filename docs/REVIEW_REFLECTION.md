# 结构化复盘：情绪、错误、结论与行动

入口：完整订单或复盘列表 → 查看交易与编辑复盘。复盘列表显示摘要及全文，并支持新增筛选。

- 入场前/退出后情绪分别记录：平静、自信、焦虑、恐惧、贪婪、挫败、冲动、疲劳、其他；允许未记录。可写 2000 字情绪说明。
- 所有情绪内容均标记“事后回忆、主观自评”，不会伪装为交易时已经记录，也不按盈亏自动选择情绪或错误。
- 错误自评分为尚未评估、未发现错误、存在错误。存在错误时至少选择一项：追单、提前入场、过度交易、报复性交易、超仓、未设置止损、随意移动止损、过早退出、拖延退出、偏离计划、其他。
- 主要错误最多一项，必须来自已选择的错误分类；删除对应分类时清除主要错误。未指定主要错误不等于没有错误。
- 复盘结论和下次行动分别最多 2000 字；可以明确选择“继续执行现有规则，无需新增行动”，与行动文字互斥。已有行动文字时选择该项，会先确认是否清空。
- 新版表单及显式传入结构化字段的接口调用，提交 `reviewed` 时要求结论和行动（或无需新增行动）；草稿允许未完成。这只是结论/行动校验，尚未覆盖完整规则评分及计划关联要求。

## 兼容和存储

迁移 `0008_review_reflection` 在 `trade_reviews` 增加 `reflection_json`，默认 `{}`。历史复盘保持原状态，未填写的情绪/错误不推断；历史已复盘但结论/行动空缺时，列表提示“结论／行动待补充”。

`GET /api/v1/my/trades/{id}/review` 及汇总列表返回规范化的 `reflection` 对象。`PUT` 可传同名对象；旧客户端省略或传 null 时保留旧结构化内容，兼容原有状态提交规则，不会清空新数据。新版客户端始终提交该对象。如需清空内容，使用草稿并显式提交空对象。结构化对象是整体替换，不是部分补丁。

字段：`recording_basis=retrospective`、`emotion_before`、`emotion_after`、`emotion_notes`、`error_assessment`、`errors`、`primary_error`、`conclusion`、`next_action`、`no_new_action`。代码枚举见 `backend/app/trades/reflection.py`，中文显示统一在 `frontend/src/lib/tradesync/reflection.ts`。

保存沿用同一复盘版本和成交摘要校验，与笔记/标签一起原子提交。旧版本拒绝覆盖；重命名标签不会清空新字段；成交变更保留自评并提示待核对。重同步保留结构化内容，在待恢复资料里可查看全文，精确恢复原交易关联后继续使用；账户删除一并清除。维护预览摘要已涵盖整条复盘记录。

## 搜索及筛选

`GET /api/v1/my/reviews` 新增 `emotion`（任一阶段匹配）和 `primary_error`（仅主要错误精确匹配）。与账户、状态、标签、关联状态共同过滤，分页总数使用同一条件，均限定当前用户。

## 草稿自动保存

交易详情中的复盘编辑器在停止输入 1.5 秒后自动保存草稿，并显示等待保存、正在保存、保存成功或保存失败状态。自动保存失败后停止自动重试，保留当前输入，由用户点击“重试保存草稿”，避免网络异常时持续请求。已复盘内容再次编辑时自动回到草稿；只有点击“提交已复盘”才执行结论和行动完整性校验并恢复已复盘状态。成交源数据发生变化时仍需用户保存草稿或重新提交，系统不会静默确认新的成交数据。

关键词搜索扩展至情绪说明、结论和下次行动，仍按字面子串，不将百分号或下划线当作通配符。列表的分析跳转只带账户、标签、复盘状态，明确不携带情绪/主要错误；按错误统计业绩尚未交付。

## 验证与限制

94 项后端测试通过，覆盖草稿/完成校验、错误主次约束、去重、长度、枚举、互斥项、旧调用保留新内容、标签维护保留、关键词/组合筛选/分页、归属隔离、旧版本冲突、成交变更、重同步保留及恢复。

下次行动目前仅是复盘中的记录，不会自动建立计划或提醒；后续每日流程模块再接入跟进状态。自评分类为首版固定分类，自定义分类和情绪强度仍待后续开发。

## 历史版本

迁移 `0009_review_versions` 新增只增不改的复盘版本表。每次保存草稿、提交已复盘或批量调整标签时，系统在同一事务内写入完整快照；账户删除通过外键级联删除历史，重同步继续保留。升级时会把每条已有复盘的当前内容登记为首个可见快照。

`GET /api/v1/my/trades/{trade_id}/review/versions` 按版本号倒序分页返回状态、笔记、标签、结构化复盘和保存时间，只允许交易所属用户读取。交易详情提供折叠的只读历史区，不会用旧版本覆盖当前输入。
